# π0.5 SAE 语义—层/模块实验进度

公开资产复用、64 个本地观测读出、六个 FFN 及三个双 FFN 组合干预均已完成。当前有离线响应结果和完整动作路径接入检查，尚无本版闭环成功率或 GPU 净加速结果。

## 已复用的成果

- 固定三个 Hugging Face 仓库的 revision，直接使用 L5/L16 SAE 权重、归一化统计和原样官方 loader，没有重新训练 SAE。
- 复用概念索引、网站预计算说明、原作者层统计、原始激活和视频/消融索引。已分析 VLM 与 Action Expert 各 18 层，共 1118 条概念—层记录；L5/L16 共有 27 个概念候选。
- 概念索引是候选池，不包含逐特征完整 d/频率，也不是排序列表；缺失统计从原始数据或小批激活补算。48265 条公开索引中 11661 条有 success 字段，缺失没有当作失败。
- 同一公开轨迹两层激活各采样 32×64 个 token，用官方 loader 实测：L5 normalized MSE=0.047153、FVE=0.995444；L16 为 0.076442、0.964708；每 token 非零数均为 64。
- 复用本地 32 条已有完整 π0.5 baseline 轨迹，提供 691 个实际请求。冻结 12/4/8 任务划分，先取发现/校准每 episode 首尾两个观测，共 64 个；没有为离线取样再采 baseline。

## 本地实际实验

- 64/64 观测捕获及两层 SAE 读出完成。前 12 个用 8 线程，其余 32 线程，真实输入上的线程变更校验逐位一致。
- 原生只读 hook、L5 后 full 尾段与原路径逐位一致。公开 L5 缓存直接重放到本地 L16 未建立等价性，因此该缓存用于公开分析，不充当本地干预输入。
- 在相同 64 个观测上比较公开候选、全字典关联和指令 token 读出。指令池 L5 可触发 bowl、stove、on；L16 全局分类不稳，但在冻结 L5 实际触发群内，bowl/on 的晚期基线证据均跨两个 episode 存在。
- 两版单模块矩阵已完成，三个实际组合为 `[12,15]`、`[6,15]`、`[12,14]`，均在发现与校准观测上验证。总计保存 138 个不同观测/mask 的物理尾段结果；换读出复用已有前向。
- 默认 `delta=0.1` 的规则为空，原结果保留。另存探索候选 `[6,15]`、`delta=1.1613027445`，只由离线校准结果选择，未读取测试 SR；它是相对影响先验，不是通过小阈值语义保真的规则。
- CPU 完整动作路径检查通过：只读 SAE 的 raw/decoded 动作与原路径逐位一致；实际在线 `[6,15]` 与直接指定同一 mask 的动作也逐位一致。针对性测试 12 项通过。
