# π0.5 隐藏表征实验结果

Source 使用实际机器人微调后的 π0.5-LIBERO；Target 是冻结的官方 PaliGemma-3B-mix-224。两者之间仅使用恒等表征注入，无训练映射。Target 用来读出表示，不负责机器人动作。

320 条样本来自 40 个官方初态派生的合成反事实，覆盖颜色、左右关系和指令×布局 2×2；按场景分为 96 条校准与 224 条独立测试。所有源边界 0…18 均完成独立测试。

## 本轮判断

**idea 得到部分支持：冻结的外部语言读出器可以从机器人微调后的 π0.5 视觉 token 块中读出部分属性，但当前结果主要属于封闭候选分类，尚未建立可靠的开放式自然语言解释。**

- **颜色读出成立但依赖上下文。** 在校准选定的 Source 3 / Target 3，视觉块候选 BAcc 在黑色控制图下为 100%，在灰色控制图下为 50%；合并为 75%。黑色控制图下成对样本都正确，错误 donor 会使答案转向 donor 的颜色。灰色控制图下没有相同的读出效果。这个差异说明结果对 Target 上下文敏感，不能把某一控制图下的失败解释为 Source 没有颜色信息。
- **左右关系有中等信号。** 视觉块在 Source 6 / Target 6 的候选 BAcc 为 62.5%（95% CI 58.0–67.0），比打乱源高 19.6 个百分点（10.7–28.6）；自由短答案 BAcc 为 61.6%。黑色控制图下为 75%，灰色为 50%，仍存在控制图敏感性。
- **单文本 token 仅有弱颜色信号。** 校准选定的 Source 9 / Target 6 在颜色候选分类上为 57.1%（52.7–61.6），空间关系仅 53.6%（49.1–58.0）。这些结果不足以称为稳定、广泛的单 token 语义解释。
- **指令条件化定位未通过本轮验证。** 视觉块候选 BAcc 为 50.0%，单文本 token 为 52.2%；两个路径在校准所选操作点的 2×2 四组全对率均为 0。单文本路径相对打乱条件有小幅差异，但准确率置信区间包含 50%，且未正确完成四种组合，不能据此宣称完成了目标绑定读出。
- **颜色自由生成没有成功。** 两个路径在所选颜色操作点均为 0%；候选标签选对不能包装成模型已能自由说出隐藏表示的含义。

颜色合并区间的 [75.0,75.0] 来自本批每个场景均呈现相同的黑／灰控制图模式，因此组级 bootstrap 没有产生抽样波动；它不代表对新场景或其他 benchmark 的不确定性为零。这里的区间是探索性、未做多重比较校正的描述性区间。

## 结果文件

- `operating_point_results.json`：完整摘要指标及每种控制图结果。
- `completion_audit.json`：原始矩阵覆盖、输入内容、工程门槛、冻结配置和划分核验。
- `image/evaluation/analysis/`、`text/evaluation/analysis/`：逐层指标、置信区间、曲线和随机生成案例。
- `image/calibration/analysis/`、`text/calibration/analysis/`：实际测得的 Source×Target 校准热图。
- 各路径 `frozen_probe_config.yaml` 和 `probe_results.jsonl` 保存完整可复核配置与输出。

## 结论边界

这里只评估这组冻结检查点、提示、层及 token 配置下的可解码性。H0 已经过视觉编码器；不能把曲线解释为语义首次出现，不能由读出失败推断信息不存在，也不能据此断言机器人动作使用了该属性。

多视觉 token 与单文本 token 的信息容量不同。深层相机位置的 token 也可能融合其他相机与指令，不能把其位置当成信息来源隔离。任务条件化成功也可能包含 Target 后续计算完成的目标绑定。所有数据均来自同一 LIBERO 场景模板的反事实，尚不证明跨任务泛化。封闭候选读出也不等同开放式自然语言自解释。

## 运行完成核验

两条路径各完成 19,200 条校准和 27,328 条独立测试，共 93,056 条正式读出记录；另有两条各 1,600 条的一场景试跑，未混入正式测试统计。全部期望矩阵单元、输入内容哈希、冻结配置和工程门槛均已核验。原始运行数据、失败输出和随机案例保留。
