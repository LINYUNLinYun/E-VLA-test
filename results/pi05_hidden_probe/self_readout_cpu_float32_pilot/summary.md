# PaliGemma 同模型隐层读出检查

复用旧校准集的 4 个颜色样本、2 个场景组。只检查读出通道，不是新的独立测试，也没有训练映射。

Source 和 Target 是同一个冻结 PaliGemma-3B-mix-224，精度 float32。提取层与注入层相同。base=agent 相机 256 tokens；all=两个有效相机 512 tokens。

same_question：源端真实图片＋颜色问题；robot_instruction：源端真实图片＋原机器人指令，目标端仍是颜色问题。

候选指标比较 red/blue 的首 token 对数概率；自由生成采用原有完整短答案解析，最长 8 tokens。

## 本轮判读

这次小检查通过：同一 PaliGemma 第 3 层的真实图片特征在黑／灰两种控制图下均支持正确颜色读出；源提示用颜色问题或原机器人指令、注入主相机 256 tokens 或两相机 512 tokens，候选打分与自由生成均为 100%。相反颜色 donor 使答案跟随 donor，说明输出受注入内容控制。

这里只使用旧校准集 2 个场景组、4 幅图，完成 108 条读出记录。GPU 2、3 持续繁忙，本轮实际执行为 CPU float32；原 GPU bfloat16 扩展没有启动，等待器已停止。不能将这次结果与旧的 π0.5→PaliGemma 数字作为仅改变 Source 的严格对照，也不能由小检查成功断言跨场景泛化或跨模型已经对齐。
