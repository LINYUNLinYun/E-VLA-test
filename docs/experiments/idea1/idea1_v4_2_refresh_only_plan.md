# V12子路径与残差外推：全部动作由子路径执行

用户指定两组各40条探索闭环，四个LIBERO套件各10task、官方init19，共80条。优先使用当前空闲GPU0/1各一个持续B1服务；不占用他人进程所在卡。实际设备按UUID绑定、领取共享GPU锁，同case两条件同卡、顺序轮换，每条件新环境，环境创建前seed7。

1. `v12_d2_only`：固定V12跳层[2,3,5,14,16,17]，所有轮次D2；没有Full刷新，没有残差补偿。
2. `v12_d2_refresh_extrapolate`：同一子路径、同一D2，每三轮（replan0/3/6…）从当前观测运行完整VLM并捕获跳层的真实FP32残差。随后重新运行V12，始终执行子路径D2动作。Full不调用AE，也没有Full动作进入环境。保留自身最近两次刷新，以实际控制步age/gap做线性外推；本轮刚刷新时ratio0，尚无第二份历史时hold。

沿用π0转换BF16 checkpoint，完整18层AE、均匀D2 Euler，预测H50、执行前R5、20Hz、10步settling、原suite上限、原prompt和case/replan噪声。两组均无验证器、无夹爪保护、无Full拒绝回退、无动态选层；不使用encoder或AE CUDA Graph。固定mask来源为前述V12补偿实验，不按本次闭环成绩重新选层。

两组统一使用修正后的OpenPI时间嵌入频率linspace(0,1,512)，不复用使用旧D2时间编码的闭环结果作本轮控制。旧31/40和169/200都是执行Full-D10动作的混合路径，仅作历史说明。

CPU针对性检查刷新日程、历史年龄、始终D2、ack/reset。每GPU在四个既有真实观测上检查无补偿V12等于原生V12前缀加修正D2、外推Triton加法等于PyTorch参考、两完整周期始终禁止Full AE。两服务固定输入输出按原atol=rtol=1e-5核对。同case初态/观测一致、所有请求D2/无Full动作、残差刷新频率和历史只来自自身过去需通过审查。有效失败不重试；技术错误最多恢复一次并归档。

保留逐case成功、动作/EEF、原始H50输出、逐请求路由和真实计时。输出四套件成功数、配对恢复/新增失败、探索区间，策略热态ms/动作（每回合排除首3请求）、含准备的墙钟和吞吐。快速质量检验优先；刷新轮当前重复视觉/VLM准备的实际成本全部计入，不宣称部署实现最优或仅靠本次自由轨迹计时证明加速。
