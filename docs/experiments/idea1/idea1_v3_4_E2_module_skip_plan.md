## 4. 模块门控与执行语义

令Attention和FFN的残差更新分别为`r_A`、`r_F`：

```text
a_l = x_l + g_A,l * Attn_l(x_l)
y_l = a_l + g_F,l * FFN_l(a_l)
```

原始贡献评分`R`在所有门控为1的完整路径求`abs(dL/dg)`。Attention门控放在FFN之前，其梯度必须穿过本层FFN和后续网络。不能用整层分数减FFN分数推Attention分数。

FFN-only使用17个FFN门控；混合使用34个A/F门控。一次标量动作投影的反传可以同时返回全部门控的梯度，不按模块逐个反传。门控数量翻倍不意味着反传次数翻倍，但新增保存张量、图构建和捕获成本必须实测。一次投影仍有正负抵消，完整35维Jacobian不在本轮主矩阵内。

原生Fast执行要真正绕过算子，不能先算完FFN再把输出乘零：

|跳过方式|保留的当前计算|省去的更新|补偿位置|
|---|---|---|---|
|FFN-only|当前Q/K/V、RoPE、Attention和输出投影|FFN gate/up/down及对应更新|Attention更新之后，加预测FFN残差|
|Attention-only|当前K/V与原层号；FFN在补偿后的输入上正常计算|可省的Q、Attention及输出投影更新|FFN之前，加预测Attention残差|
|同层A＋F|当前K/V与原层号|两种特征更新|按A后F的顺序分别加两种预测残差|

当前AE逐层读取VLM的K/V，因此三种模式均保留**本次观测的KV**。Attention skip的省时要按原生KV-only路径计算，不能把整套QKV都算作可删除。参考实现入口为`preparations/idea1_v3_4_v12_compensation/backend.py`和`policies/realtime-vla-flash/scripts/spec/triton/pi0_infer.py`。

## 5. 模块残差补偿与误差方向评分

Full需分开采集`r_A=a_full-x_full`与`r_F=y_full-a_full`，FP32保存。整层残差`r_A+r_F`不能直接用于单独FFN补偿。

FFN-only保存本episode全部17个FFN的最近两次真实Full残差；混合保存A/F各17份。保存实际环境步号与prompt/shape身份。预测沿用：

```text
r_hat(t) = r_last + (t-last_step)/(last_step-older_step) * (r_last-r_older)
```

首周期hold；正常R5下随后四Fast的age为5/10/15/20、Full gap25，比例0.2/0.4/0.6/0.8。Full不补偿；候选使用自己的观测、当前KV和Full历史。FFN-only先保留全部Attention，不额外预测它。

补偿误差评分`E`：第三个Full起，先用**本次Full之前**的最近两次历史预测本次残差，再求`e=r_current-r_hat_current`。在模块输出处使用中性门控：

```text
module_output(g) = module_full_output - (1-g) * e
```

`g=1`保持可微Full路径，`g=0`沿“真实模块更新换成预测更新”的误差方向扰动。该门控必须在相应模块之后、下一个模块之前；Attention误差的梯度仍穿过FFN。误差来自原生Full采集，须记录与PyTorch近似回放的边界。

计算`e`之后才把当前残差写入历史。前两个Full沿用本结构的原始贡献评分：整层E回退整层R，FFN-E回退FFN-R，混合E回退混合R。正常情况下第三Full在step50首次产生E评分，新mask从step55的Fast开始影响动作。原始/误差同结构的暖启动前缀应匹配。

当前Full误差只是后续Fast误差的代理，不提前读取未来观测或真实FFN输出。离线可运行真实FFN检验预测，但这些oracle结果不得进入在线选层。原生FFN残差的变化、补偿后动作误差和重要性须分别报告。

## 6. 成本预算与选模块规则

先在真实同输入、同噪声上测模块增量省时，包含KV-only差异、跳过后的补偿加法和实际kernel路径。定义`c_m`为可省时间、`s_m`为动作敏感度代理。`s_m/c_m`用于解释排序，正式选择为：

```text
minimize sum(s_m for skipped modules)
subject to B - tau <= estimated net saved time <= B + tau
           B is the B4 or B6 time-saving anchor
           all masks satisfy the spacing rule
```

- B4/B6从相同观测库中既有整层skip4/6原生路径的省时冻结，不能看闭环成功率后调目标。`tau=max(0.5 ms, 1%锚点Fast时延)`只作用于总预算一次，不能逐模块累计放宽。
- FFN原始/误差评分使用相同成本表和合法候选集。FFN无补偿消融也沿用FFN有补偿时冻结的预算与候选集，只移除补偿操作，不另调跳数。
- FFN候选可枚举全部间隔集合；对每个预算保留同一成本窗口内的mask。固定随机也从这一窗口均匀抽取，避免给它任意更多跳数、造成额外损伤。实际跳数、支持层数和估计省时逐次记录。
- 混合候选每层有keep/A/F/AF四种状态，用带间隔状态的动态规划或等价搜索，不穷举`4^17`。成本离散误差上限启动前冻结并报告，例如0.01 ms；需核对量化前的真实预算。
- AF不能假定省时恰好等于A＋F，须测其组合成本。若搜索用`s_A+s_F`作AF误差代理，明确它是局部可加近似，不能当成整层Jacobian；对选出的联合mask做同输入原生反事实复核。
- 非正收益或小于测量噪声的模块省时不作为预算贡献，保留原始读数。不得用理论FLOPs替代实测成本。

原生验证实际Fast时延。若候选比锚点慢超过上述tau，不称作同预算收益。若整数模块使成本窗口内没有合法mask，只按成本选择最近的可实现档位并冻结，报告其实际Pareto点，不看成功率调宽窗口、不插值得到虚构成功率；相关随机对照也使用同一档位。更快的候选可作为“相同或更低耗时”比较，但必须列出差额。Full采集/评分及完整五请求成本另算；Fast满足预算不代表整周期一定满足。
