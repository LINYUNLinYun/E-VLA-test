# v3.4 E2/E4：PyTorch 单层机制实验

2026-10-29。用户授权只执行新增 E2/E4，先获得单层证据；E1/E3 不重跑，不开展多层 mask 搜索或新闭环。

## 共同实现与数据

复用 v3.4 的 40 task、init14 Full 真实轨迹及已冻结的 160 对观测。保持输入、prompt、state、H50、R5、原 request noise、D2 均匀 Euler。同一个 released π0 fused checkpoint。固定视觉嵌入由既有原路径提取一次；VLM、KV shell、完整 AE/两步 FM 使用独立纯 PyTorch functional 实现，冻结模型权重，以 FP32 做可微机制诊断，不将其数值或耗时冒充原 BF16 Triton 部署结果。记录四 suite 输入上的 PyTorch/native 差异；主要科学对照全部在同一 PyTorch 后端内完成。不会因跨后端差异反复追求逐位一致。

每层在更新 hidden 之前产生本层 K/V；跳层保留该 shell。L18 只有 K/V，无残差更新，故测试 L1–17。gate 定义 h_out=h_in+g*(block(h_in)-h_in)，gate=0 的动作与实际 bypass 对照，gate=1 与无 gate 路径对照。用真实输入做有限差分检查 autograd。若内存/数值技术问题，先修实现并保存版本记录，不能用放宽科学判据掩盖。

## E2

每 task 固定取原四个 pair 中第二个，共40个请求，独立于任何动作误差。对 Full 基点前5步×7个有效动作维求完整 gate Jacobian；不对动作 MSE 求梯度。每个单层分别 gate=0.9/0.5/0 实际前向，预测 (g-1)*J_m，保留 raw H50、Jacobian、实际扰动。平移、旋转、连续夹爪与 decoded 夹爪符号单列。报告向量相对预测误差、方向余弦、实际影响与预测影响的 Spearman、低影响候选漏判；加入原层输入输出余弦、残差范数排序。随机投影2/4/8的范数估计用固定独立投影种子与完整 J 比较；先不将其上线。原定义中“每T次刷新”的部署收益留到本轮证据后，不开展多层验证。报告完整 Jacobian与单次forward成本。

## E4

使用全部160个原固定 pair；按 suite 内 task 分组，偶数 task 0/2/4/6/8 校准80请求，task1/5验证32请求，task3/7/9留出48请求。同轨迹各请求不跨split。每个单层独立 bypass，其他层 Full。无补偿为基线，Full为参考；预测、日程、噪声一致。

五种方法全部做：a 通道均值/标准差配准，b 正交 Hadamard 域相同配准后逆变换，c 最近历史Full同层残差相加，d 两次历史Full残差按实际控制步外推，e ridge闭式残差回归后SVD低秩近似。a/b参数仅来自校准；std下限1e-6，scale固定clip[0.1,10]。e ridge=1e-3*mean(diag(X^T X))，rank8/32，由验证组按平移最低且夹爪差不高于无补偿的候选选择；若均不满足，选夹爪差最低，再按平移打破并列。每请求固定抽32个均匀视觉token和最多16个均匀语言token拟合，避免视觉token数压过语言且控制拟合成本。SVD随机种子固定，无梯度优化。

c/d的历史使用本条Full参考轨迹的过去真实观测，属于teacher-forced机制诊断，不是候选自身闭环。最近Full年龄5步；第二次Full从最近Full之前至少15个控制步处取最近可用请求。缺第二历史时d回退c，显式标记并单列有历史子集；不跨episode/不使用未来。缓存/外推成本计入，不假定Full刷新免费，不报告部署加速。

关键输入分布检查：同一层分别在Full输入和由原V14中该层之前的skip生成的输入上评估补偿至当前Full层输出的hidden误差；这是单层补偿的输入鲁棒性诊断，不是多层策略成功率。e另用这些实际偏移输入在校准集拟合相同rank，比较Full-input拟合与shifted-input拟合。a/b和e均不能使用验证/留出数据拟合。

保存前5步/全50步平移控制命令差代理、旋转命令L2、夹爪符号差、raw误差；Full轨迹上的误差不解释成真实EEF误差或任务成功率。按suite/task等权汇总，留出组配对task聚类bootstrap探索区间。模型路径测速固定每suite的task0第二个pair，共4个不同真实输入，各层各路径预热后AB/BA三次；科学候选用共用Full前缀缓存以减少重算，测速单独跑完整编码路径、不把共享计算当作部署收益。
