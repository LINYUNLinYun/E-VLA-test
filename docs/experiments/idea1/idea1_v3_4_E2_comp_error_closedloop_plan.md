# 补偿误差方向的一次VJP闭环初筛

2026-10-31，用户已授权在开销可控后测试闭环可行性。V14/V12各40个已冻结匹配case，共80条新闭环；复用cycle3_extrapolate的同预算原Jacobian加外推，以及同40case的固定V12加外推参考，不重跑已完成条件。

保持Full-D10→Fast-D2→Fast-D2、H50/R5、完整18层AE、保留当前K/V shell、最多连续跳2层。V14跳4层、V12跳6层；时间权重[1,2,4,8,16]/31，七维正等权，热态每次Full一次VJP。实际执行Full始终为原生BF16 Triton；求导为已修正初始语言输入的完整D10 PyTorch重放。

每次Full采集全部L1–17的真实残差R_t，仅保存本条件自身轨迹最近两次Full及实际执行步号。第三次Full起计算e_t=R_t−[R_last+((t−last)/(last−older))*(R_last−R_older)]。误差方向在每层Full hidden输出处通过x(g)=y−(1−g)*e_t注入，g=1保持Full输出；一次VJP同时取得17层对加权动作的误差方向敏感度，按abs梯度之和选择满足max2的skip4/6组合。e_t是最近已观测的外推误差，用作下一周期Fast误差的代理；没有提前读取未来Fast观测或真实残差，不宣称直接获得未来真实补偿误差。单次投影抵消和联合跳层交互仍存在。

前两次Full沿用原Jacobian选层，后两个Fast照常残差复用/外推；第三次Full才切换误差方向。该选择在看结果前固定，不调整暖启动或权重。新旧同预算方案在前30个执行动作、第三次Full的动作和其后首Fast输入上应相同；第三次Full产生的新mask从step35的Fast开始影响闭环。误差计算必须在新残差放入历史、丢弃旧历史之前进行。既有两份历史加当前Full已足够，不额外执行探测Full。

Fast补偿完全沿用已验证实现：Rhat=R_last+(age/gap)*(R_last−R_previous)，正常age5/10、gap15，比例1/3、2/3；首周期回退复用。保留层当前计算，跳过层在hidden更新处加预测残差，所有K/V来自当前观测。Fast不选层、不反传。

场景沿用四suite奇数task1/3/5/7/9×init19/20，共40case。独立Fresh环境，构建前seed7，env_seed7、settling10、20Hz及原步数上限。两预算同case同GPU、轮换顺序，噪声按case/replan固定；有效失败不重试，技术失败最多重试一次。仅调度无计算进程且占用≤1500MiB的空闲GPU，尊重其他会话占卡。

前置门禁复用已通过的8个真实输入、240组GPU配对：中性门控保持Full输出、误差公式与FP32参考一致、Graph/eager梯度最大差0，误差方向评分比原评分平均增加1.018ms/Full。另针对新策略做恒定真实观测下两预算的10轮Full/Fast路由检查：暖启动、三个Full历史步号、误差源比值、恒定观测误差为零、Full/Fast输出与相同Native Full上下文D10/D2一致、Fast零额外选层。失败不放宽容差。
