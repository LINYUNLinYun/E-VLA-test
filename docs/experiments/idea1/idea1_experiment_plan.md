## 1. 研究目标与需要收紧的推断

主线：从同一完整 VLA 中提取无需权重训练的快速路径，测量其在不同任务和操作阶段的短时可靠性，再研究自适应执行 horizon 的成功率—实际延迟权衡。

主贡献优先级为“短时 draft + 自适应执行”；phase-aware mask 是候选优化手段，视觉解耦不是首轮必要组件。最终报告 Pareto 曲线，不预设可接受的成功率下降。

以下均是待验证假设，而非已有结论：

- 不同套件成功率不同，不足以证明某一层的重要性随场景或 phase 改变。任务难度、时长与 baseline 成功率不同也会造成差异。
- V13-Custom 的全程成功率不高，不能据此证明短前缀不可用；同样不能反过来证明短前缀一定可用。
- 最后进入抓取阶段才失败，不等于此前没有偏离；首次偏离与最高到达阶段须分别分析。
- D10 改为 D3 是重新离散化完整积分区间，不能据此推断 D10 最后七步只是无用精修。
- 高余弦、低激活或低离线 NMSE 都不能单独证明可安全剪层。
- draft 与 Kalman 预测一致不是任务正确性保证；两者可能同时沿错误方向预测。
- 已执行的物理动作不可回滚，后续校正不保证恢复到原轨迹。

已有报告中 Full18 四套件总体为94.4%，V13为43.75%；V13新增失败中1035/1036在baseline接触/靠近前已经出现持续2cm轨迹差异。这反驳了“多层裁剪只在精细操作阶段才有问题”的一般化说法，但轨迹差异本身也不等同于错误。

早期端到端观测曾记录Full18约43.55ms、D3约35.72ms；这些是不同口径的历史测量，不能与本轮隔离的模型/backend p50直接比较，也不能沿用“数百ms”作为本系统事实。本轮有效独占计时见第12.8节，排除了simulator/RPC/video，不代表端到端延迟。当前跳层实现保留每层K/V投影，跳过hidden的Attention/FFN更新，不能按删除数估算完全移除block的收益。

相关工作需在研究表述中对齐：[A³](https://arxiv.org/abs/2605.11567)已研究自适应执行前缀，[KERV](https://arxiv.org/abs/2603.01581)已研究Kalman辅助与动态阈值。新颖性不能仅落在“动态阈值”上，应检验同权重连续动作快速路径、阶段mask与可恢复短前缀的组合价值。

## 2. 公共协议与四卡执行预算

- 四个标准套件：libero_object、libero_spatial、libero_goal、libero_10。
- 每任务仅官方 init0–4：50 episodes/suite、200 episodes/条件，不默认扩展到50个初始状态。
- 每套件 task0–5 为搜索任务，task6–7 为验证任务，task8–9 为冻结后探索性评测任务；都只用五个初始状态。
- 参数与mask不能由冻结评测任务选择。历史实验已经看过这些任务，须说明这是本轮搜索隔离，不是严格未见测试。
- 固定 checkpoint、输入变换、环境 seed=7、warmup=10、参考执行窗口12。基线为 Full18 VLM、完整 Action Expert、D10。
- 离线成对干预共享观测、state、prompt和原始噪声；噪声种子12345/23456/34567。统计不把噪声重复或同轨迹观测视为独立任务。
- 已有结果只有满足配置、输入、噪声规则和记录要求时才复用；复用的成功率与新采集的激活须明确区分。
- 小样本用于研究初筛，不宣称无损或充分泛化；不稳定时提出定向补测，不自动扩展。

四卡采用单卡单worker，最多四个并发实验任务，不做模型并行：

- 离线按mask或观测×噪声分片，闭环按条件×套件×task组拆分，单任务固定init0–4。
- 尽量保持模型常驻，完成一个job立即领取下一个；独立端口、日志、输出目录和GPU绑定。
- 空闲卡才使用，不抢占其他任务；无空闲卡每5分钟检查一次，不频繁轮询。
- 完成键包含配置hash、权重hash、suite/task/init/seed；断点续跑核查覆盖，不重复计数。
- 成功率可四卡并行，正式延迟另安排同卡独占测量，轮换条件顺序。不得混合不同GPU或争用状态的耗时。

## 3. 实验1：数值特征与干预敏感度联合分析

### 3.1 要回答的三个不同问题

1. **数值活动是否不同？** 同一层在不同任务/阶段的 hidden、Attention/FFN 更新幅度和分布是否改变？
2. **动作敏感度是否不同？** 固定输入与噪声，跳过这一层造成的动作扰动是否随阶段改变？
3. **这种差异是否具有可用价值？** 按阶段选择mask，是否比同预算静态mask提供更好的短前缀与恢复率？

实验1重点回答前两问，第三问必须由后续短时分支和动态mask实验回答。不能只看激活数值就宣布阶段剪层有效。

### 3.2 参数与激活必须区分

推理期间参数 W 不更新；不同场景不会导致同一层的权重发生训练式变化。因此：

- 权重范数、绝对值分位数、精确零比例可以每个checkpoint统计一次，用于结构描述、尺度诊断与异常排查。
- 权重hash在干预前后核验，确保未改变权重；“权重变化”不是场景敏感度指标。
- 随输入变化的是激活 H、Attention输出、FFN输出及最终动作。数值分析的主体是这些中间张量。
- 不能把某层大权重、更多非零参数或更多非零激活直接解释成该层更重要。

### 3.3 样本来源、分层与覆盖

使用训练好的模型与真实 Full18 rollout，不使用随机图像或随机初始化网络。随机的是固定种子的动作生成噪声，不是机器人观测。

在重规划时点采样，按现有语义标签分组：

- approach：initial/approach；
- contact_grasp：contact/grasp_or_manipulate；
- transport：transport；
- alignment_release：goal_alignment/release_or_final_action。

每episode每组最多取首个、中间、末个有效时点；去重，保存原始step、原始阶段和分组阶段。success不单独生成后验“安全样本”。缺失阶段不补造，保留baseline失败轨迹。

每个样本保存双相机、机器人state、语言prompt、EEF/物体真值诊断、阶段证据、来源路径与hash。物体真值只能用于离线分组和解释，不输入在线路由器。

先按episode聚合，再按task聚合；任务等权。每个suite×phase提供任务数、episode数、观测数。少于3个搜索任务的阶段不建立该suite的阶段专用结论；不能用同一任务的许多帧弥补任务覆盖不足。

### 3.4 记录位置与默认数值指标

对VLM层L1–L17记录：

- H_in：block输入；
- H_attn：Attention残差相加后；
- H_out：FFN残差相加后；
- Δ_attn = H_attn − H_in；
- Δ_ffn = H_out − H_attn；
- Δ_block = H_out − H_in。

L18单独标记为KV-only：当前H18=H17是实现行为，不可把零hidden更新当成无用层。

按agent-view、wrist-view、有效language token分别统计，不把视觉token数量优势混成总体结论。忽略padding，并记录有效token数。

| 数值指标 | 默认记录 | 解释与限制 |
|---|---|---|
| 幅度与分布 | 均值、标准差、RMS、abs值p50/p90/p99、最大绝对值、NaN/Inf计数 | 说明输入/更新尺度，不直接代表任务重要性 |
| 更新强度 | RMS(Δ_attn/Δ_ffn/Δ_block)、相对Frobenius残差 | 比较模块对hidden的更新大小；分开看可发现相互抵消 |
| 方向变化 | 同token余弦，attn前后、ffn前后、block前后分别测 | 高余弦可能遗漏关键小幅更新 |
| 表征结构 | centered linear CKA，按模态、同输入成对计算 | 作为补充，不与token余弦混同 |
| 精确零比例 | mean(X==0) | 只描述实际dtype输出；零少不意味着更重要 |
| 近零比例 | mean(abs(X)≤α×RMS(X))，α=0.001/0.01/0.1 | 使用相对尺度并扫描阈值；全零张量单独标记 |
| 更新集中度 | 每token更新范数的p90/p50及贡献最大的前10%token占总更新能量比例 | 检查少量关键token是否被平均值掩盖 |

上述指标默认对H与三个Δ张量统计。Attention输出更新和FFN输出更新是主分析对象，不把Δ_ffn的近零比例冒充FFN中间门控神经元稀疏度。

FFN门控中间值、Q/K/V及注意力熵只对主分析挑出的最多4个候选层加做诊断，以避免大量张量存储和额外kernel改写。注意力熵需要真实概率，不能从Attention输出范数倒推。

BF16输出转FP32/FP64后做统计，记录原dtype；转换不能恢复此前丢失的精度。零向量、常量张量、无language token及CKA零分母记为undefined并输出有效数，不伪造相似度。异常NaN/Inf导致该样本验证失败。

### 3.5 成对干预：从数值活动走向动作敏感度

每个相同观测和噪声生成：

- Full18完整基线；
- 分别跳过一个VLM层hidden更新的18个干预，仍保留K/V投影；
- 干预后的完整基线复测。

捕获路径和普通路径必须先通过baseline parity。若重复基线发生数值差异，保留诊断，定位执行/编译差异后再分析，不把差异混进剪层效果。

对动作前h∈{1,2,4,8,12}步分别记录：

- 前三通道translation命令RMSE、后三通道rotation命令RMSE；
- 夹爪连续值误差、以执行器阈值0定义的符号不一致率；
- 训练归一化动作空间的NMSE，平移和旋转分开，并报告绝对RMSE和基线能量；近零基线的NMSE单独标注；
- 每horizon在不同观测上的均值、p50/p95、最坏案例。

不要把translation命令RMSE写成实际EEF厘米误差。数值接近完整模型也不保证动作本身正确；完整模型失败样本须单独标记。

Attention/FFN子模块干预只对最多4个候选层开展：分别跳过Attention输出残差或FFN残差；Attention干预仍保留Q/K/V，结果不得与整层干预混同。

### 3.6 如何判断“阶段/场景敏感度不同”

主要证据来自干预效应，不是参数活动。令I(t,l,p,h)为task t中跳过层l后、阶段p、前h步的成对动作扰动，先聚合噪声与观测，避免伪重复。

预先指定h=4的归一化连续动作RMSE为主要阶段比较指标；其他h、NMSE、夹爪和激活统计为补充。归一化使用checkpoint的固定输入/输出变换，不能每阶段另选尺度。

区分三类结果：

1. **阶段整体更敏感**：所有层在contact阶段扰动都更大，可能是动作幅度或状态更难，不足以支持换mask。
2. **层×阶段交互**：不同层的相对敏感度或排名在阶段间改变，才是phase-aware候选依据。
3. **任务限定交互**：只在某suite或少数task成立，不能推广为通用phase-aware规律。

默认统计与图形：

- 每suite制作layer×phase数值活动热图、动作敏感度热图及逐任务配对轨迹线；热图同时附覆盖数。
- 在有两个阶段的同一task内计算层敏感度差；以task为单位bootstrap 10000次给95%区间，并做leave-one-task-out稳定性复核。
- 阶段差异进一步扣除该task所有被测层的共同阶段变化，报告层相对变化，避免把所有层一起变大误称为层排序变化。
- 针对阶段对与层的探索性检验，以task为单位符号翻转；任务数少时枚举所有符号，明确离散p值；多比较用Holm校正。不能把同一轨迹帧当独立重复增加显著性。
- 小样本的检验分辨率必须单独审计：双侧符号翻转在n个配对task下最小p为2^(1−n)。本轮搜索最多n=6、每suite的层×阶段比较族含102项，最小p=0.03125大于Holm首步0.05/102，任何数据都无法通过这个门槛。保留预先约定的校正，但不把全体不显著当作无交互证据，也不在看结果后换检验追求显著。此轮以效应量、任务级区间、LOO稳定性和冻结后的闭环比较进行探索；若需要确认性结论，再明确提出增加独立任务/预先缩小比较族的下一轮设计，不用增加同task的帧数冒充独立任务。
- 检查horizon、噪声种子、任务和phase采样方式下排名是否稳定；若删除任一task就反转，结论标记为脆弱。
- 同时报告原始动作尺度、基线能量、phase时长及轨迹进度；阶段标签与接触/夹爪事件高度相关，观测分组不构成“阶段本身导致层重要性变化”的因果证明。

需要的证据链是：活动差异 → 成对干预差异 → 稳定的相对层差异 → 冻结任务上的复核 → phase mask相对静态mask的闭环收益。任一环不成立，报告相应负结果。

### 3.8 补充：数值分析的具体比较与判读协议

数值分析有必要，但须区分证据职责：要证明“某层在某阶段更敏感”，核心证据是同一观测、同一噪声下的成对跳层干预及其动作影响；仅有激活统计不能证明敏感度。激活数值分析则回答“该层在不同输入/阶段的计算活动怎样变化”，用于解释干预效应、定位Attention/FFN及提出候选先验。权重范数、零比例等是固定checkpoint的一次性结构描述，不能作为阶段敏感度证据。

因此，实验1按以下优先级执行：

1. **核心、不可省略：功能敏感度。** 逐层skip的成对动作误差、layer×phase效应与任务级不确定性；这是阶段敏感度结论的主要依据。
2. **必要解释集：激活/更新数值。** 至少记录每层Attention、FFN、整块残差更新的相对RMS、前后hidden方向相似度、更新幅度分布（含尾部）和相对近零比例，并按模态、task、phase汇总。精确零比例只作补充描述。该集合用来解释层间及阶段间差异，不独立决定剪枝。
3. **定向诊断、非全量门槛：参数与内部子模块细节。** 权重矩阵统计每个checkpoint做一次；Q/K/V、FFN gate中间激活、注意力熵及token/通道定位只对最多4个候选层按需补测。若资源受限，先保证前两层级，不能为了补齐所有诊断而重跑全部闭环。

“活跃”不应简单定义为参数或激活非零：推理时权重不随样本变化；而残差更新即使数值小，也可能承载关键的方向信息或被后续层放大。反过来，更新较大也可能被后续计算抵消。故方案同时保留更新幅度、方向/尾部统计与成对干预效应，并把“数值特征与动作影响相关”限制为搜索集内的解释性关联，不表述为因果或剪枝安全证明。

**第一步：固定权重的数值体检。** 对各层Attention的Q/K/V/O投影和FFN的gate/up/down投影分别记录shape、dtype、参数量、RMS、abs分位数与零比例。只比较结构相同的矩阵，不把不同形状矩阵的总范数直接排序。权重只统计一次，不做“不同阶段权重变化”曲线；低零比例也不意味着不能裁剪。若存在融合、量化或特殊布局，记录映射关系，不凭名称推断模块含义。

**第二步：真实样本的更新强度、方向与集中度。** 除3.4的默认指标，再补充以下有针对性的诊断：

| 诊断 | 定义/做法 | 希望排查的问题 |
|---|---|---|
| 尺度匹配的模块更新 | r_attn=||Δ_attn||F/||H_in||F；r_ffn=||Δ_ffn||F/||H_attn||F，按模态分别算 | 不能因输入尺度不同，把绝对更新大误解为更重要 |
| Attention/FFN抵消 | cos(Δ_attn,Δ_ffn)，以及 c=||Δ_block||F/(||Δ_attn||F+||Δ_ffn||F) | 整层更新小可能是两个大更新相互抵消，并非两个模块都冗余 |
| token尾部与能量集中 | 更新token范数分位数、top10%能量占比；索引回映射到图像patch或语言token | 平均余弦很高，是否仍有少量关键区域发生大更新 |
| 通道集中度 | 对hidden通道计算更新能量分布、top10%通道占比 | 是否主要由少量通道承担更新；不将其直接解释成可删除其余通道 |
| 输入依赖的分布变化 | 同层同模态比较各task×phase的r、余弦、近零比例与能量集中度 | 活动模式是否随场景/阶段改变，而不只是全层统一放大 |

以上Frobenius指标仅在同一张量形状/有效token集合内计算；不同模态之间同时报告每元素RMS和token数。分母为零时标记undefined，并保留分母与有效数，不用任意epsilon制造可排序的极大比值。抵消分析是在实际残差流上做数值诊断，不能据此宣称Attention与FFN功能可互换。

**第三步：把数值特征与干预效应接起来。** 为每个layer×task×phase×模态建立成对记录，将更新比例、余弦、近零比例及集中度与该层skip的h=4动作扰动对应。先画逐任务散点与分阶段曲线，再在搜索任务上计算Spearman相关、任务级bootstrap区间和leave-one-task-out稳定性。层与帧不是独立重复；同时给出按层内、任务内比较，避免“不同层天然尺度不同”造成伪相关。验证任务只检验冻结的关系，不重选阈值。

重点展示四种案例，而不是只挑支持裁剪的图：

- 小更新、低干预误差：优先候选，但还需组合与闭环验证。
- 小更新、高干预误差：关键小幅信息或下游放大；禁止仅凭高余弦裁剪。
- 大更新、低干预误差：存在下游补偿或对当前动作不敏感的可能，不能直接称为无用。
- 大更新、高干预误差：保留优先级较高，并定位敏感模态/阶段。

**第四步：候选层的子模块复核。** 仅在搜索任务选最多4层，覆盖上述不同案例；对同输入同噪声分别比较完整层、skip-attn、skip-ffn、skip-both。记录动作扰动及重复baseline parity，并分析两模块干预是否存在非加性交互。不能用“整层skip误差减去attn-skip误差”替代FFN独立干预。中间gate激活/近零比例只用于解释FFN；非零率高低本身不是模块敏感度。

**第五步：场景与阶段的区分。** “场景”首轮操作化为suite/task，不把suite当作唯一视觉场景变量。阶段差异优先在同task、同init的轨迹内配对，再以task为聚合单位；缺少成对episode时显式报告，不能用不同episode的混合均值冒充轨迹内变化。跨suite差异只能称任务/场景关联；若要判断背景、物体位置等因素的独立作用，另行设计保持任务与机器人状态尽量一致的受控观测扰动，不从当前观察性分组直接推断。

**输出与实施边界。** 在3.7产物中增加module_cancellation.csv、activation_intervention_links.csv、候选token/通道定位图和子模块干预对照表。每项注明“已采集/可由现有统计推导/需补充probe”：相互抵消、通道集中度、token定位和模块独立干预可能需要额外记录，现有汇总不能恢复的信息不得伪造。先利用已有数据完成核心分析，再对最多4层定向补测；不为补图重新跑全部闭环。本文补充的是分析与补测方案，不代表这些新增诊断已经完成。

## 4. 实验2：启发式mask组合搜索

历史设计：本轮候选提出与闭环覆盖已由第9、12节替代；尤其不再执行beam/Pareto粗精筛，不把禁止相邻删除作为硬规则。

### 4.1 主搜索规则

- 固定保留L1/L2/L17/L18；禁止相邻两层同时删除。
- 分别计算每个有效task×phase×模态单元的相邻余弦中位数，再取这些单元的第10百分位。稳健分数低于0.98的层在主搜索保留。
- 高余弦层仅为候选；同时用单层动作扰动引导，不直接按余弦删层。
- 搜索删除2/3/4/5/6层，5层预算与V13等预算比较。若合法组合数为0，明确报告预算不可行，不偷偷放宽规则。
- 0.98是启发式先验，不是动作安全阈值；阈值和保护层由搜索分区冻结。

### 4.2 搜索算法、预算与挑战规则

- 受约束beam search逐次增加删除层，每深度最多评价128个新mask，保留8个。每次真实测组合，不相加单层分数。
- 根据各horizon的尾部动作误差、夹爪不一致及均值做非支配排序；超额时用目标空间拥挤度保持多样性，最后按层编号确定性打破平局。
- 从优秀组合做同预算“恢复一层、删除另一层”，最多三轮；加入固定种子的随机合法候选。
- 全局最多1000个不同mask，含beam、换层和探索；每阶段专用搜索最多256个。评估缓存绑定数据/权重/噪声/配置hash。
- 新候选评估90%遵守规则，10%每次只放宽一种：允许一对相邻删除、允许删除L2、或允许删除一个低余弦层。L1/L17/L18始终保留。
- V13含相邻删除和低余弦层，作为独立参考。找与它差异最小的合法5层mask，最多8个作为额外起点；不存在合法5层组合时如实记录。

### 4.3 多级淘汰

- 粗筛：搜索task init0每phase首个有效观测、一个共享噪声种子。
- 复核：最多16个前沿候选，在搜索task的五个init全部采样集、三个种子上复测。
- 验证：每预算最多两个候选进入验证task的短时分支/恢复实验。
- 闭环：最多两个静态mask和一套阶段mask进入200-episode初筛。
- 搜索先固定完整Expert/D10；优秀mask再组合D3/D5，组合重新验证。

速度对晋级候选做实测；不把层数当实际延迟。离线排序不预测恢复率时，以恢复证据为主，保留错配分析。

## 5. 实验3：完整区间少步积分与数值质量

- 对比D1/D2/D3/D4/D5/D10，每个D覆盖完整积分区间，不执行D10的前D步冒充少步采样。
- 另记录D10每步中间状态和当前向量场的终点外推；明确中间量不一定是可执行动作。
- 同噪声记录每步更新范数、前缀动作误差、夹爪一致性与短时分支质量，不能从更新变小直接认定后步无用。
- 新D1/D2/D4各200 episodes；D3/D5/D10仅在协议一致时复用历史子集。
- 单独测encoder/prefix/decoder和端到端时间，考虑固定成本限制，不按步数比例宣称总加速。

## 6. 实验4：短前缀、分支执行与Full18恢复

历史设计：本轮实验4以第11、12节为准，必须依赖实验2选出的跳层方案，且环境始终只执行full。下述旧分支/恢复流程不在本轮执行范围。

无需等待搜索完成，先比较Full18-D3、V16-D10、V13-D10、V13-D3；后续增加冻结搜索mask。

对h=1/2/4/8/12分三层证据：

1. Shadow：只执行Full18，同观测比较draft。
2. 同状态分支：执行完整模型和draft前缀，测真实EEF位置/姿态、物体状态、夹爪与接触差异。
3. 恢复：draft执行h步后，从新观测切回Full18；与全程Full18比较成功率及剩余完成步数。

分支必须恢复环境、控制器、随机与计数状态；仅qpos/qvel不足。不能可靠克隆时独立环境重放相同历史动作，先校验下一步一致性。先做代表性分支筛查，最多两个现有draft进入200-episode恢复初筛。

分析首次持续XYZ/姿态偏离与最高阶段，不能只按最终阶段归因。保留完整模型自身失败情况，不预设其动作是真值。

## 7. 阶段mask与两阶段自适应执行

先确认层×phase差异，再寻找阶段mask。阶段覆盖不足时不生成专用mask；真值phase只用于离线/oracle。

在线phase proxy仅使用夹爪变化、EEF速度及控制命令；阈值只在搜索/验证task标定，不读取物体真值，未知/不确定时使用完整模型。报告与真值phase的混淆矩阵。只有phase mask优于同预算静态mask，才支持阶段路由有收益。

第一阶段“先验证再执行”：Full18/draft同观测，分别判断平移、旋转和夹爪；只接受最长连续前缀，验证成本全部计入。可能无净加速，应如实报告。

第二阶段“先执行后校正”：

- 仅用通过短分支和恢复筛查的draft，提前长度扫描1/2/4/8/12。
- Kalman基于已执行动作前六个连续控制通道做命令预测，夹爪独立处理，不冒充完整动力学或语义验证器。
- 协方差归一化残差阈值取验证集50/75/90/95分位数，冻结后评测。
- 超阈、夹爪切换、观测超龄或历史不足时禁止提前执行。
- 请求、观测、动作全部带版本和时间戳。旧Full18结果不能直接接在改变后的轨迹上，必要时从最新观测重规划，计入额外成本。
- 已执行动作不能物理回滚，恢复失败是重要指标。

必要对照：Full18-D10、D3/D5、draft全程、固定horizon周期回退、Kalman-only、自适应静态mask、自适应phase mask；真值phase仅oracle。每机制最多两个验证后设置进入200-episode初筛，不全参数闭环网格。

先在原生20Hz控制下实测；人工50/100/200ms延迟下限及物体扰动仅在冻结后用于代表性task诊断，单独报告，不替代标准结果。视觉解耦等真实观测年龄证明有问题后再做，不同观测/mask的KV不能混用。

## 8. 接口、验收与停止条件

实验入口支持任意删除层集合、显式init列表、预算、约束、噪声和数据划分；不沿用旧runner自动扩展50状态的逻辑。probe已有任意mask干预入口；晋级mask需与生产路径对齐并验证parity。D1/D2/D4须补完整积分权重与执行验证，不能只改CLI步数。

实施验收：

- baseline普通/记录路径和干预后复测parity、权重hash未变；
- 全零/常量/不同模态token数、BF16/近零阈值、缺失阶段、近零动作能量的数值测试；
- 人工构造“全层一起变大”与“层排名反转”的数据，验证统计不会把全局phase主效应误写成layer×phase交互；
- mask/KV对齐、相邻/保护层检查、不可行预算、去重与断点覆盖；
- 分支一致性、积分完整区间、连续前缀接受及过期请求处理；
- XYZ使用真实位置，蓝色baseline/橙色变体透明点线，姿态/夹爪曲线与同步MP4；视频完整解码。

报告同时提供原始表、层/子模块/模态数值热图、动作干预热图、mask来源与违反规则项、逐任务分子/分母、恢复率、首次偏离、阶段计数、同卡延迟与系统开销。

若没有优于V13的候选、phase mask不优于静态mask，或自适应系统不优于D3/D5，都保留负结果。达到搜索预算或已有足够明确的趋势后停止，不自动启动全量评测。

- 全部D10检查仍做相同四套件、每任务init0–4，最多7个条件×200=1400条。加上主要评测，**不复用时总预算最多7600条**；实际新增数减去已验证可复用的对照。D10诊断不影响29个候选全部完成D3闭环的要求。
- 分别报告同mask的D3−D10配对成功率差，以及相对Full18的差中差：`[SR(mask,D3)−SR(Full18,D3)]−[SR(mask,D10)−SR(Full18,D10)]`。区间按suite内任务聚类、task/init配对；posthoc选出的少量mask只能提供交互线索，不代表所有29个mask都不存在交互。
- 主要结论明确限定为“D3条件下的跳层方案比较”。未经D10复核的mask不能称D10同样安全；成功率和实测时延表必须同时注明mask与D值。

历史pipeline计时曾记录D3约26.59ms、D10约34.36ms（约22.6%单次耗时差）；其测量程序/计时边界与本轮`isolated_d3_metadata.json`不同，不能与本轮模型/backend p50混算或据此声称端到端加速。这类步数诊断只作低优先级交互检查。环境步进、渲染、视频编码、冷启动与失败跑满步数仍影响总耗时。D3必须覆盖完整积分区间，不能执行D10前三步冒充D3。

### 9.3 候选提出：已有证据引导，不做新的离线淘汰

1. 使用已有真实baseline样本的稳健余弦、单层skip前4动作扰动、夹爪翻转率，以及跨suite/task/phase的稳定性。记录样本来源、计算口径与覆盖；当前主要余弦证据是各block输入→输出相似度，不伪称已具备任意两层完整两两矩阵。不能用随机初始化输入或参数非零率替代任务证据。

## 10. 26.10.10 补充研究：任务类型 × Layer / Attention / FFN 重要性

### 10.1 要检验的主张与理论边界

在第9节29个变体直接评测的基础上，进一步探索：**同样的层或子模块，对不同任务类型是否具有不同的重要程度，能否形成可复现、具有实际裁剪价值的任务依赖性。** 此项不恢复离线粗筛—精筛，也不减少任何已冻结候选的四套件直接评测。

用户提出的分层直觉作为待检验假设：Transformer较前层可能偏向提取/组织较通用特征，较后层可能更突出某些任务相关特征；这种分工也可能具体到某层的Attention或FFN。**不把这一说法写成当前VLA已经成立的一般规律。** 多模态融合、残差、每层KV和下游Action Expert都可能使功能跨层分布；某层也可能同时承担多类任务所需信息。幅度小、高余弦、强Attention权重或通道集中均不单独证明功能或冗余。

任务类型按LIBERO定义操作化，而不是把三个suite称为三个房间场景：

| 类型 | 主要变化因素 | 本研究关注的问题 |
| --- | --- | --- |
| Spatial | 同类物体的空间位置/关系，按指令选择目标黑碗并放到盘子 | 空间关系相关信息的干预敏感度是否依赖某些层/子模块？ |
| Object | 目标物体类别不同，抓取指定物体并放入篮子 | 物体类别相关信息的干预敏感度是否不同？ |
| Goal | 相同物体、固定空间关系下改变目标与操作要求 | 目标/动作行为差异是否对应不同的层/子模块敏感度？ |

LIBERO-10保持四套件闭环覆盖，但作为混合、多步骤任务的补充检验，不强行归为第四个单一能力。三个suite设计方向不同，不代表只测一种能力；suite之间同时存在动作类型、难度、时长与任务组成差异。

预先区分三个假设：

- H1（任务依赖）：层/模块干预影响存在任务类型相关差异，不只是某个suite所有干预都更难。
- H2（深度分工）：相对早层，部分后层的任务类型选择性更强；也允许无趋势、反向或仅中层最强的结果。
- H3（模块分工）：同层Attention与FFN的类型选择性不同，或联合干预存在非加性交互。

旧D10探针中L13对Goal/Spatial的动作扰动高于Object、L3跨suite较稳定、L17数值幅度与动作敏感度不一致，仅作为提出假设的已知线索，不视为新假设的独立确认。

### 10.2 第一层证据：直接评测所有mask的任务类型差异

复用第9节全部29个mask、Full18-D3和原始V13-D3的四套件五状态数据，不新增全量50状态评测。对每个mask在每suite计算：

- 成功数/50、每task成功数/5、实际动作数和任务结束情况。
- 同task/init相对Full18-D3的配对成功率差、新增失败和恢复数；baseline本来失败的任务不得误计为裁剪新增失败。
- 同删除预算内不同mask的配对比较，以及各mask在三个suite上的相对排名；检查是否出现可复现的排名交换，而不是仅统计某suite总体更低。
- 类型差异采用相对baseline的损失：`Delta(mask,suite)=SR(mask,suite,D3)−SR(Full18,suite,D3)`，再报告`Delta(mask,A)−Delta(mask,B)`。不能用原始成功率的差直接解释层的重要性。
- suite内部以task为聚类单元、保留init内配对；不同suite的task不是同一任务，跨suite差异需要分别重采样各suite任务，不能伪造跨suite task_id配对。分别展示效应量、任务分布、区间和leave-one-task-out稳定性。baseline接近满分的天花板效应、全失败的地板效应和任务时长差异单独报告；差中差不自动消除所有难度混杂。

**多层mask的类型差异首先只能归于“组合”。** 例如[3,10]对Goal损失更大，不足以判定L10负责Goal，更不能仅按“包含L10的mask都差”归因：层共现、删除数、相邻性及组合交互都可能造成偏差。29个mask不是随机全因子设计，层包含/不包含的回归或相关只作描述，不作为单层因果证据。

候选提出时，在不改变第9节数量与直接评测要求的前提下，尽量为各删除预算保留结构相近的一次换层对照，并登记层包含矩阵。一次换层会同时恢复一层和删除另一层，只能比较两者在该背景mask下的相对效果，不能独立识别任意一层的作用。较前/较后层删除比例也须记录，防止把更激进的mask误当成后层更重要。

### 10.3 第二层证据：单层任务敏感度与数值/表征特征

先用已有单层探针按suite、task、phase、模态重新汇总；旧数据固定D10，其结论必须注明D10。对应新D3结论需有D3诊断，不能更换标题就当作已测。D3诊断使用来自Full18-D3真实轨迹的代表观测，同输入同噪声比较完整模型与单层干预；它用于机制解释，不淘汰29个直接闭环候选。

采样仍以task为独立单位：尽量保持suite间阶段配额与每task贡献一致，分别给出task-equal和共同阶段支持下的分析。缺失阶段、未到达精细阶段及失败轨迹选择偏差显式标注，不补0、不因某suite样本多而加权更多。阶段、噪声及模态不当作独立任务；三个suite有各10个任务，不用帧数制造大样本。

测量包括：

1. **动作干预**：前1/2/4/8/12动作的连续扰动、平移/旋转分项、夹爪翻转和逐task尾部误差；主要指标预先固定前4动作RMSE。尾部风险与均值并列，原始归一化误差和物理命令误差区分。
2. **数值更新**：各模态H_in/H_attn/H_out和Attention/FFN/block残差的RMS、相对范数、分位数、近零比例、token/channel能量集中度；BF16转FP32不恢复此前精度，零比例不等于参数稀疏率。
3. **表征关系**：层输入输出余弦与可用CKA，明确方向、幅度和分布是不同证据。若需任意层两两比较则定向保存真实hidden张量，不能从现有汇总恢复不存在的全层矩阵。
4. **任务选择性**：在每task/phase内扣除各候选层共有的干预强度后，比较层的相对suite效应/排名，检验layer×suite交互；同时报告未中心化结果，防止全局尺度差异或L1极端值支配结论。L1结构强干预单独展示，L18 KV-only不进入“可删hidden层”排名。

“前层通用、后层专门化”的预设描述分组可用L1–L5、L6–L12、L13–L17；连续深度趋势同时报告，不能只选有利分组。各层的任务类型选择性根据相对干预效应定义，而非仅根据类别分离/范数。层数不是额外独立任务，不能把17层×帧数当作显著性样本。若使用简单冻结线性读出预测物体/目标标签，只解释信息可解码性；类别或指令token可被直接读出，不代表模型利用该信息生成正确动作，也不能据此命名某层功能。

预先固定少量主要对比（例如L13相对L3的类型差异、早/后层组的选择性趋势），报告任务聚类区间和小样本检验分辨率。广泛的所有层×所有suite×所有特征探索另列，并按明确比较家族控制多重性；不重演每suite上百项检验却只有5–6独立任务、Holm拒绝在数学上不可达的设计。未通过校正不等于无差异；单个bootstrap区间不跨0也不单独证明功能分工。

### 10.4 第三层证据：定位到Attention或FFN

在全层动作/数值结果中选最多4个有明确不同案例的层：跨类型稳定低影响、类型选择性较强、数值变化与动作影响不一致，以及更新抵消/模块交互显著的候选。记录选择发生在评测前还是后；后选层的结果为探索性，不能当独立确认。

对同一真实观测和噪声，分别运行完整模型、skip-attn、skip-ffn、skip-both/整block干预。保持当前KV语义及完整专家D3，核查各模式与普通运行路径parity；“保留FFN”会使FFN读取Attention干预后的输入，单模块干预与整层干预不是可相减的独立分量。每种模式分别汇总Spatial/Object/Goal的动作影响与阶段覆盖。

定向记录Attention/FFN输出的token和通道更新分布，区分agent/wrist/language；观察任务依赖性是否集中于某模块或局部位置。若采集Attention概率/熵或FFN gate中间值，需真实张量和额外采集校验；不能用Attention输出幅度推导概率/熵，不能把delta_ffn近零率当gate神经元稀疏度。强Attention权重也不是因果重要性的充分条件。

如发现明确模块选择性，再选择最多2层做Attention-only、FFN-only和必要整层对照的**直接闭环**补测，仍为各task init0–4、D3、同协议baseline；新增条件和episode预算单独登记，不隐含加入第9节7600条上限。先确定配置与额外预算再执行，不默认跑所有层×所有模块×所有suite。模块方案没有闭环证据时只称离线诊断，不称可部署剪枝方案。

### 10.5 因果、泛化及可用价值的验证边界

suite效应混合了任务难度、操作行为、时长与观测分布。要进一步归因于空间关系/物体类别/目标信息，需少量受控对照：在可行的同一模拟布局/机器人状态下改变目标指令，或构造保持其他条件尽量一致的物体位置/类别差异；确保目标物体存在、目标可完成，并为每个条件重新获得完整模型参考。固定画面改指令可做离线诊断，但不冒充新环境闭环；单张图像像素编辑或不可行指令不能直接用来证明真实任务能力。

当前40任务及历史样本已被查看，基于它们提出/选择的规律属于探索性。若存在“某层/模块对某类型特别重要”的强线索，应先冻结具体预测（哪些层、哪个模块、哪些类型、效应方向和指标），在额外代表任务或尚未使用的初始状态/噪声上验证；独立seed不能替代独立任务证据。追加验证规模和权限单独确定，不自动扩展为50状态全量。

只有实际任务信息可在线获得、且独立验证支持收益时，才考虑按任务类型选择mask。用已知suite标签选择最优mask先作为oracle上限，不能称完成通用场景识别或在线自适应；同一评测数据挑最佳mask再报成绩有选择偏差。最终更强主张需要任务识别的可实现性、失败回退及真实时延收益。

### 10.6 产物与结论分级

新增分析产物为mask×suite成功率/相对损失热图、同预算排名交换图、layer×suite单层动作敏感度热图、早/中/后层选择性趋势、Attention/FFN×suite对照、数值/动作影响散点，以及逐task分子分母、覆盖/缺失记录和类型差异的XYZ/失败阶段示例。数据表含D值、mask/模块语义、样本来源和选择阶段，D3与D10分别报告。

结论按证据分级：

1. 只有mask成功率差异：称“组合具有任务类型相关的性能差异”。
2. 有单层/模块干预、task稳定性及难度/阶段核查：称“存在任务依赖的重要性证据”，仍不直接命名功能。
3. 有受控输入变化和独立复现：才更有依据把作用关联到具体空间/物体/目标信息；允许功能跨层分布，不要求每层一项独占能力。
4. 有实际闭环任务路由与净收益：才称“任务类型自适应裁剪具有可用价值”。

本节补充的是任务类型机制研究设计，不代表Attention/FFN或定向干预probe已执行。Experiment 11的29个候选D3直接闭环及有限D10复核均已完成。定向单层/模块诊断可作为下一优先研究，但不得与D3/D10闭环结果混成一个分母，也不得自动追加闭环预算；开始前须冻结样本、指标、输出目录和预算。Attention/FFN闭环及受控输入验证仍需另行授权。

## 11. 26.10.10 实验4修订：官方动作块执行下的全轨迹配对Shadow

### 11.1 用户确认的流程与覆盖优先级

本节覆盖第6节下一轮实验4的主要流程：**沿完整模型实际轨迹持续比较full与variant的未来动作预测，始终不执行variant。** 先前实际短分支与Full18恢复回答的是另一问题，保留为历史补充结果，不能冒充本项完成。原shadow只采阶段代表观测，也不能称为全轨迹持续比较。

按OpenPI官方LIBERO示例的动作块方式：模型一次预测50个动作（`action_horizon=50`），full只执行前5个（`replan_steps=5`），之后获取新观测重新规划。参考代码：[Pi0Config](https://github.com/Physical-Intelligence/openpi/blob/main/src/openpi/models/pi0_config.py)、[LIBERO客户端](https://github.com/Physical-Intelligence/openpi/blob/main/examples/libero/main.py)。5是该示例的客户端默认执行窗口，不是所有pi部署环境不可更改的模型常数。

每条episode按以下顺序运行：

1. 在当前重新规划时刻t获取真实obs（两路相机、机器人状态、指令），记录环境step、实际时间及阶段信息。
2. full与各variant对完全相同的obs和同一初始动作噪声分别预测50动作；顺序运行/多卡分发不影响env状态，候选结果不写入执行队列。各模型隔离buffer/KV/随机状态，variant诊断不能改变full输出。
3. 对每个variant计算第1–50个动作各自的配对差异，以及前h=1/2/3/4/5/8/12的前缀指标；前1–5动作是主分析，后续offset只作诊断。保存原始预测，不以差异决定是否让variant执行。
4. **只将full的前5个动作放入执行队列，逐个调用env.step()；这5步内不把队列替换为重新预测的第一个动作。** 中途成功则立即终止，不为了凑满5步继续执行。
5. 队列耗尽后，在新obs上重复1–4，直至full成功或达到suite标准步数上限。所有重新规划点都比较，不只抽每阶段首/中/末观测。

比较horizon与执行窗口独立：H12表示比较本次预测前12动作，不表示环境执行12步；之后5步获得新obs会重新预测。统计点默认位于环境step0、5、10……，并非每个env.step都重新规划。每环境步仍保存full真实telemetry，用于阶段/接触定位。若后续确需每步预测诊断，另加不覆盖full队列的shadow，单独记录额外成本，不默认改为replan=1。

本轮第9节闭环评测与实验4均统一replan=5，但它们仍是不同实验：前者执行各变体以测成功率，后者只执行full以诊断配对预测。旧12步轨迹只能作为另一协议参考，不能复用为新5步轨迹。同协议新Full18基线若从采集起完整保存所有重新规划点的obs/噪声/预测，可按第12节复用于shadow。

### 11.2 控制变量与变体配置

full表示完整VLM与完整Action Expert层结构，不自动等同某个D值。纯VLM跳层比较沿用用户已确认的D3约定：full=Full18-D3、variant=相应mask-D3，两端降噪步数一致。必要Full18-D10与mask-D10比较独立登记；若研究单独少步降噪，另列Full18-D10对Full18-D3，不把它混成VLM裁剪效应。执行5动作与降噪D3是两个独立参数。

四套件、task/init0–4、环境seed、checkpoint、输入变换、warmup与噪声规则保持同协议配对。一次full轨迹可供多个variant共用观测并做shadow；在同一D值和执行协议下不为每个variant另跑不同full轨迹。候选回传顺序不推进模拟器，额外GPU只并行预测任务；full噪声计数不被variant调用消耗。

**实验4依赖实验2的真实闭环结果选择跳层mask，不由D3-only方案、旧离线搜索获胜者或预先随机mask替代。** 按第12.4节选择最多4个满足80%总体成功率的预算代表，加原始V13诊断参考；若没有合格新mask，报告实验2负结果，不擅自取消门槛并宣称实验4主比较已完成。四卡可以按suite/task拆分并共享相应轨迹观测，或并行variant诊断，但禁止混用不同观测/噪声的结果。无空卡5分钟检查、已由本实验占用时按完成事件调度的规则不变。

上述是原正式主名单的冻结准入规则；2026-10-11用户指定的V14_A03补充候选按第11.6节独立登记，不受原80%自动门槛排除，不改写历史主名单。

### 11.3 要检验的现象：简单运动与精细操作的预测差异

用户假设：沿同一full轨迹，variant在简单平移/接近时与full较接近，到接触、抓取、目标对齐、夹爪释放等精细操作时差异可能增大。**这是实验要检验的预测，不是预先保证出现的结果。** 平移本身不一定简单，搬运可能持续有接触约束；反之大动作也不一定高风险。

阶段用full实际telemetry中的接触/抓取、物体位移、目标距离、姿态变化和夹爪命令辅助划分，规则与阈值记录；它们仅用于实验事后诊断，不被variant用来控制机器人。先按接近、接触/抓取、搬运、对齐/释放报告，同时另标注低旋转/无夹爪切换的平移区间。缺失阶段不补0，不按预期挑选阶段；临界重新规划点允许标注阶段转换或混合窗口。未来h动作是否跨阶段只能用full后续实际阶段辅助说明，不能称variant未来阶段已被观察。

### 11.4 沿轨迹记录的指标与可视化

- 每重新规划点、variant和h：前6维连续动作的归一化RMSE，反归一化后平移/旋转命令误差、夹爪开合符号不一致率；分项、逐动作offset误差和尾部风险与平均值并列。不要把动作控制命令直接称世界坐标末端位置或真实姿态轨迹。
- 记录baseline各窗口动作幅度，分别报告绝对误差与分母明确的相对误差；baseline接近零时相对误差不可定义或需显式floor，不能因为精细阶段命令小就造成比值爆炸并称差异更大。
- 每条轨迹形成`环境step/时间 × variant × horizon`误差曲线/热图，叠加full阶段区间、首次真实接触和夹爪切换位置；这样检验差异是否在精细阶段升高，而不是比较两条已经走偏的执行路线。
- 同task/init配对比较简单运动与精细操作窗口；先轨迹内汇总，再任务等权，报告不同suite、不同mask、不同h的趋势和任务覆盖。相邻窗口高度相关，帧/预测offset/噪声不当独立任务；未到达后阶段的full失败轨迹、成功轨迹条件化分析与全体轨迹结果分开。
- 保存full真实EEF XYZ/姿态/夹爪及视频；同步画面旁展示variant预测动作误差与h曲线。**不存在variant实际执行XYZ轨迹**，不能伪造橙色“实际轨迹”。预测命令用蓝/橙曲线区分；如果另做经验证的运动学转换，也只标预测/近似轨迹，不能替代真实执行位置。

新Full18基线也必须replan=5；不接受旧12步结果冒充匹配基线。50是模型每次调用的输出动作块长度，5是从该块实际执行后重新观测的窗口；执行5步后丢弃未执行尾部。更短执行窗口意味着更频繁反馈、较少陈旧观测下的开环偏移，但会增加重规划调用；更长窗口可摊薄调用成本，但纠偏更迟。本轮固定50/5是与当前LIBERO runner一致的比较折衷，不代表π0/π0.5所有版本的普适官方默认，也不代表5已被证明最优；不扫描1/2/10/20执行窗口。后45个动作未执行不等于生成时无作用，不能为了省时把模型预测长度直接改为5。Luna Max接手须以实际冻结配置及runner核对50/5，不得仅凭“PI默认”说法改参数。

### 12.3 实验2候选冻结、覆盖与预算

- 新mask预算固定为V16×10、V15×8、V14×6、V13×5，共29。原始V13 skip=`[3,4,7,12,15]`作为额外参考，不计入5个新V13。
- 提出依据必须链接已有真实观测的相似度/干预指标。没有完整两两层相似度矩阵时，如实写block输入输出余弦；D10先验不能冒称D3测量。
- L1/L17/L18是本轮硬保留，L2和低余弦层是可挑战偏好。每个家族至少一个相邻删除候选、至少一个分散删除候选；V13至少两个原始V13的一次换层邻域，至少一个不相邻且保留L2的候选。其余用不同证据来源保持多样性，不把一个单层排序复制29次。
- 相邻删除不禁止，也不优待；“原始V13可以删除L3/L4”不能推出任意连续层均可删。名单冻结后不根据成功率临时换层、减候选数或提前淘汰失败方案。
- Luna Max需先生成`candidate_manifest.json`和便于阅读的表：variant_id、family、skip/retain、删除数、依据、例外、原始指标引用、D、replan、checkpoint/config hash。校验29个不同新mask、预算正确、历史同mask不重复计新；不存在足够可解释候选时报告缺口，不重启组合粗精筛填数。
- 实验2主预算6200 episodes：29×200+Full18×200+原始V13×200。D10复核最多1400，总闭环上限7600；新协议不匹配旧数据时必须重跑对照。
- 按9.4优先完成基线、原始V13和5个新V13；其余照固定队列全部评测。所有29个主条件完成后冻结排名并选择实验4输入。

若分析某个相邻对的交互，优先用已有单层干预与本轮组合数据作探索性解释。单独定义`I_ab−I_a−I_b`不能当作严格可加标量因果效应；应保存动作扰动向量，检验联合干预是否明显不同于两个单独扰动的向量和。没有同输入/噪声的单层及双层控制时，只能称组合差异，不能称已证明功能补偿。需要新干预时先登记额外forward预算，新增闭环条件另请用户确认。

### 12.4 实验4变体由实验2结果确定

**选择依赖的是本轮真实闭环成功率，不是离线相似度排名。** “80%以上”按四套件等权总体成功率≥80%理解，即完整200条至少160条成功；同时列四个suite的分子/50和对Full18的损失，不能掩盖单suite崩溃。

1. 每个删除预算从合格新mask选一个，最多4个；先按总体成功率降序；总体成功率相同才用同卡专门计时的pipeline中位数升序打破平局，仍相同时按variant_id确定性排序。时延attempt无效/未完成时不臆造速度值；可按成功率完成候选选择，但不得作加速结论。无合格mask的预算空缺，不降低门槛。
2. 主展示方案为入选者中删除层数最多的一种；例如有合格V14则必须展示该剪4层方案，不能只拿Full-D3当draft。若它没有实测速度收益，仍可作诊断，但不得称快速可部署路径。
3. 原始V13额外作为诊断参考，最多5个shadow mask；它不因加入参考就变成合格新方案。只在单suite达到80%的方案可标为类型限定线索，本轮不自动扩大shadow名单或称通用方案。
4. 保存`selected_shadow_manifest.json`，包含实验2结果路径/hash、筛选口径、完整排名、缺失预算、所选skip集合与理由。D10仅作独立交互诊断，主shadow两侧仍D3。
5. 若所有新mask均不达80%，先交付实验2负结果，实验4主比较标记“未满足依赖”；询问用户是否允许低成功率mask用于纯前缀诊断，不能自作主张换成降噪变体完成任务。

上述选中方案的成功率是探索性选择依据，不是独立确认。全程成功率门槛是本轮选材规则，不能据此宣称低成功率mask一定没有可用短前缀。

**2026-10-11候选补充覆盖上述自动准入规则中的V14空缺：**用户指定V14_A03成为后续候选，具体mask、已有成绩、6979点补充Shadow规模与独立manifest要求见第11.6节。原主队列的80%门槛仍按其冻结时口径解释，后续补充必须包含该74%候选。

### 12.5 实验4全轨迹Shadow：推荐实现和执行断言

为复用同一full轨迹并避免反复跑模拟器，**推荐实验2新Full18-D3对照从采集起保存全部重新规划点的原始双相机、state、prompt、原始噪声、完整full预测、变换后环境动作和hash**。终止前每个重规划点均保存，而非实验1的阶段首/中/末抽样。图像保存无损原始数组/PNG和输入dtype、shape、预处理配置，不从有损MP4反解出图像充作相同obs。

实验2结束并选定mask后，离线逐点给variant回放这些完全相同的full输入；每条轨迹按step0/5/10……比较到full结束。该方式与在线shadow回答同一配对预测问题，但必须标为“baseline全重规划点回放”，不声称variant推理期间环境继续实时运行。模拟器只有full动作进入；若输入不完整，则新采200条full轨迹并在每个重规划点比较，不能用旧12步或稀疏观测填缺口。

实现须满足：

- Full与variant各自独立buffer、KV、CUDA graph和随机流；异步/顺序variant调用不得消费Full RNG或覆盖Full动作队列。
- 新普通full与记录路径在同输入/噪声下先通过parity；插入多个variant、改变variant调用顺序后Full输出及已执行动作保持不变。用同后端复测保存输入/噪声和full预测；不能忽略图捕获或dtype差异。
- 完整动作预测、执行前缀分别存储；trace中每个env动作都有full infer_id及offset。非终止chunk恰好5步，终止chunk可1–5步；settling warmup单独计数，不混成模型预测执行。
- 对所有200条baseline轨迹的全部重规划点都比较每个入选mask。共享一个full预测，不为每个mask另造full路线；断点恢复也不额外推进环境。
- 保存原始float32预测（归一化与反变换后有效通道）、输入hash、噪声hash、mask/D、环境step、阶段与完整时间戳。无效/缺失预测标记异常重试，不作高误差值凑统计。

预算：最多5个mask×全部200条full轨迹的重规划点数；这是forward预算，不计为5×200条variant闭环。主协议一份噪声，不默认额外三种噪声。完整baseline输入合格可零新增环境episodes；否则最多新增200条full采集，连同实验2上限为7800环境episodes（smoke另登记）。先用smoke实际测磁盘和每重规划点推理量，再给预计剩余时间，不能按成功率预算推算shadow时长。

### 12.6 短前缀分析：主要指标、阈值与不能声称的结论

主问题是“变体最前面多少动作与full足够接近”，不是整个50步动作均值。必须保留每个offset的平移、旋转、夹爪差异；主图突出offset1–5，另画1–50诊断曲线。前缀聚合h=`1/2/3/4/5/8/12`同时报告均值、最大误差、夹爪切换分歧及p95，不让后20步误差压掉前3步信息。

任务类型和动作阶段是两种不同分层：任务类型按suite并下钻到task；动作阶段按Full真实执行轨迹中的平移/接近、接触/抓取、搬运、对齐/释放标注。每次重规划后Full实际执行的offset 1–5可以用telemetry和事件标注阶段；offset 6–50没有在该次重规划后真实执行，默认只做offset诊断，不冒称其真实阶段。若要对6–50做阶段映射，只能使用预先规定、可审计的Full后续动作/状态映射，并把它标成估计标签、单独做敏感性分析。所有阶段结论都报告覆盖数、未知标签和Full自身成功/失败分层；不同suite间的成功率或误差差异不能独立证明是“场景导致层敏感度变化”。

定义参考一致前缀：给定平移阈值τT、旋转阈值τR，前h每个动作都满足两阈值且夹爪开合一致，则该h通过；`K`为首个不通过动作前的最大连续前缀长度，首步不通过时K=0。不能跳过第2步差异而接受第3步；前缀平均误差小也不代表每步通过。

**本轮未确定可部署的物理安全阈值。** 默认交付原始误差、`K(τT,τR)`曲线及阈值表，不随意将某个数写成“安全”。如需有限阈值网格，仅用Full任务0–5确定两组尺度：平移/旋转命令范数的任务等权p50，各取1%/5%/10%作相对尺度网格（9个阈值对）；注明变换后命令单位、尺度来源、零尺度时undefined，先冻结网格再看所选mask结果。这只是参考一致性诊断，不是机械臂位置毫米阈值或线上门控设置，不使用task6–9调阈值挑最好结果。

按任务类型、full实际阶段报告`P(K≥1/2/3/4/5/8/12)`、K分布、首次超阈类型和阶段转换；主分析全体full轨迹，另列full成功/失败分层。任务等权、task聚类区间、阶段覆盖、未知标签、动作幅度一起报告。尾部误差和夹爪提前切换必须展示，不只报平均。接近阶段≠简单平移，接触阶段≠一定高误差，允许相反或无差异结果。

前缀长度与推测执行等待的联系只作可行性诊断：以实测控制周期Δt与独占计时讨论full、draft完成时间以及验证/传输开销需要覆盖多少动作。不能假定有K就有净加速，不能用快模型早返回的时间直接称任务加速；同卡串行与双卡并行时间不能互相替代。当前不实际执行draft，不输出“推测系统成功率”或“已验证安全”。

预测命令差异不等于实际EEF误差；实验4没有橙色实际XYZ路线。若要证明短前缀执行可用，另行授权后做真实分支/恢复及部署时序验证。Full是参考策略不是动作真值，双方差异也可能是不同有效解。

### 12.7 四卡调度、门禁、异常与完成键

- 四卡最多四worker，GPU/CUDA可见索引与EGL实际设备绑定检查；四卡并行指实验任务并行，不要求多agent或模型并行。不能只为shadow默认占两卡一组。
- Scheduler使用跨本实验worker的原子job领取和GPU租约；新旧实验目录不同也不能各自认为同一GPU空闲。PID/租约与外部占卡信息联合核查，不能按“利用率瞬时为0”抢已被其他人占用的卡。
- 仅无可用卡/有待用外部卡时每300秒发现空闲卡；本实验占有卡通过worker完成事件立刻续派。四卡都是自己运行时不反复nvidia-smi；PID/CPU进度检查不是GPU扫描。
- 每worker独立端口、日志、输出目录。成功率多卡并行；时延选择单卡独占、warmup后随机轮换条件、CUDA event同步，报告preprocess/vision/VLM/action decoder/output transform及pipeline、RPC、环境/视频耗时的不同口径。阶段计时尚未实现时写缺项，不拿拟合截距冒充VLM实测。
- 正式执行前CPU验证：mask数与索引、保留层、D3全区间、init0–4、replan5、队列缩短终止、噪声/hash、零动作相对误差、首个失败截断K、缺失阶段、唯一完成键。dry-run输出完整job表但不创建GPU进程。
- Preflight检查共享磁盘余量、模型/环境依赖、ffmpeg/ffprobe、端口冲突；smoke后用实际每episode存储量和suite最大步数保守估算整轮空间，保留至少20%估计余量。不足则报告并等待存储安排，不偷偷省略原始输入/XYZ/视频，也不删除历史结果腾空间。
- 获用户启动授权后，在可用GPU做最小smoke：Full、原始V13、一个新mask同task/init的初始化/parity/trace/video检查，再测试多mask shadow顺序隔离和中途终止；smoke单独目录，不混入正式分母。
- 完成键至少包含实验模式、checkpoint/transform/config hash、skip/D/replan、suite/task/init、噪声规则/seed。仅通过trace/预测/视频验证才记`validated`；进程退出0或summary存在不足以完成。
- 普通任务失败/超步数正常计入成功率；异常、OOM、server退出、NaN、缺帧、错误mask、错误init均记`invalid`。同一可恢复运行异常最多重试2次并保留尝试日志；重复parity/协议不一致直接暂停该路径排查，不放宽容差或算作失败掩盖。
- Full18是实验有效性对照，不设定跨suite相同的成功率目标。若同协议Full18与已验证参考结果明显不一致，或总体成功率低于80%，先暂停对变体的解释，核查checkpoint/变换、观测与init、mask/KV、D3积分、噪声和视频/telemetry；确认是有效模型表现还是运行链路问题后再继续。suite间差异本身不触发重跑或人为调参；不得无证据归因，也不得直接套用旧control约21%的结果解释本轮。
- GPU无空闲不是错误，不触发重试风暴；permission/缺checkpoint/不可恢复数据问题停止相应阶段并报告，不绕过限制。

每个Full重规划点读取完全相同的图像、状态、语言和初始噪声，Full与各候选各输出50个动作。真实轨迹沿原Full前5个动作推进，之后获取新观测重规划；剩余45个预测不执行。已有缓存完整时直接离线重放，不为补数据另建环境。不得执行variant的一个动作，也不得将其预测滚动成虚构的末端轨迹。

首版沿 Full 真实轨迹进行预测比较，V14 和 Kalman 不控制主环境。Kalman 输入截至预测时刻已真实执行的历史动作命令，V14 与 Full 使用当前同观测/状态/提示/噪声预测50动作。禁止将当前 Full 预测后缀输入 Kalman；它只能访问已发生的历史。已有缓存和动作时间线完整时优先离线复用，不重复 GPU 调用。

三者统一比较平移控制命令：分别按相同控制器规则 clip、缩放至物理目标增量单位。Kalman 首版对历史三维平移命令建立“命令值及其变化率”的线性状态模型；该状态中的变化率是命令变化率，不能标成真实机械臂速度。报告 Kalman–Full、V14–Full 及 Kalman–V14 差异，保留有符号轴差、L2、分布尾部和分阶段结果。逐 offset1–50，重点展示1–5和1–12；这是预测命令的一致性，不是未来真实 XYZ 误差。

普通连续 Kalman 不承担夹爪开合决策；夹爪沿用 V14–Full 单独分析。旋转如补充，先明确表示与周期性处理，不与平移毫米合并为一个含混指标。加入低成本“保持最后一条已执行命令”参考，用于辨别 Kalman 是否优于简单历史延续。

#### 16.3.1 状态递推与测量校正的区别

用户所说“以上一步最优估计作为下一步起点”，若指状态递推，就是正常预测，允许且必须做。连续50次预测会更新预测副本的状态和协方差，并非将状态冻结50次。

无已知外部控制输入的线性首版模型：

`x[k+1|t] = F x[k|t]`

`P[k+1|t] = F P[k|t] F^T + Q`

从当前后验 `x[t|t], P[t|t]` 复制预测副本，连续执行50次 predict，得到固定起点的50步预测。不能把每次预测当成独立真实测量再执行 correct/update：即使创新为零、均值不变，普通测量更新也会错误收缩协方差，相当于凭空增加信息。

主滤波器按真实已执行命令的时间顺序推进；每有一条真实历史命令，按其时间戳 predict/correct。预测副本只外推，不污染主滤波器。后来获得真实数据时，更新主滤波器，并从新时刻另起一次预测。明确区分“每帧用真实观测校正后做一步预测”与“固定时刻一次预测未来50步”；二者不能混报为同一预测长度。

动作命令作为此动作空间滤波器的观测，观测噪声 R 表示模型采用的噪声/失配假设，不冒称机械臂位置传感器精度。若以后另做真实 XYZ 预测，另建以仿真器真实位置为观测的滤波器与数据表，不能将命令直接累加成实测或准确预测位置。

#### 16.3.2 时间、调参与无未来信息边界

- 时间步长固定为实际环境动作周期，不能为了贴近 pi 输出任意调整。与每5动作一次的重规划周期分开；按真实时间戳对齐到下一待执行动作。
- 用少量完整轨迹作校准，调 F 所采用的运动模型及 Q/R、初始协方差；按完整 task 或 episode 划分校准/评估，不能把相邻帧随机拆开造成泄漏。校准名单、搜索范围、选择指标和最终参数冻结留档；校准数据不混进主评估成绩。
- episode 边界重置滤波器，不跨任务串历史。明确起步无历史/历史不足的初始化规则与覆盖分母，不用未来帧初始化，不因误差大而删除冷启动样本。
- 固定起点的预测在1–50范围内不接收未来真实数据。Full真正执行仅前5步；后续重规划后的真实动作不能当成原始50步动作块的同一参考。
- Kalman 与 V14 分歧大不自动表示 V14 错误：主动停止、转向等情况下，Full和V14可能共同偏离历史外推。结合两者各自对Full的误差及事件分析，再讨论门控价值；本实验不直接部署以分歧为依据的门控。

预测/校正文档参考：[MathWorks predict 与 correct](https://www.mathworks.com/help/control/ref/extendedkalmanfilter.predict_method_state_estimation.html)。实现不依赖 MATLAB，文档用于澄清数学定义。

### 16.4 实验3：使用仿真器信息的阶段路由

用户允许直接使用仿真器当前及历史状态，包括目标物体距离、接触、抓取/持物等信号，快速验证“已知阶段时路由是否有收益”。明确这是使用额外仿真状态的验证，不声称已实现仅凭视觉部署的阶段识别器，也不用完整轨迹事后标签指导当前动作。

首版在每次重规划时判断阶段：允许使用变体的阶段执行实验2的2:1策略；接触、对齐等指定精细阶段全部使用 Full；离开精细阶段后重置交替计数，从 V14 开始。执行块仍为5步，不额外插入每步中断，以免同时改变执行窗口。持物搬运不能仅因位移以平移为主就归为简单阶段；信号、阈值、优先级及持物处理须在实现前冻结。

记录阶段判断来源、每次路由结果、Full实际调用比例、成功率与总推理开销。用户的阶段性提升预期保留；较高成功率与更多Full调用应一起报告，不能仅以成功率提升推断相同计算预算下更优。
