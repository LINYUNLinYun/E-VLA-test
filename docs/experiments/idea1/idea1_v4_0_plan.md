# idea1 v4.0：三项快速验证

按 idea1.md v4.0 做三个独立探索实验，完成后停止，不做自动扩样或大规模调参。

共同设置：π0 原 BF16 权重、FP32 RMS，Full 原生18层 VLM/D10，Fast 原生 D2；H50/R5，周期3；候选 L1–17，禁止相邻跳过；tau=.10、双时刻 .10/.05 验证和夹爪保护保持；每次实际 Full 更新全部17层残差并保留本路径最近两次历史。四个原投影、原层 RMS 分数相加规则保持。只保留选择器已有的四方向物理批量＋反向融合 CUDA Graph；encoder、AE、验证均不上图。

1. **Kalman 初始动作**：固定 V12+D2+普通评分+外推补偿+验证，比较 Gaussian D2、Kalman D2、Kalman D1；另加 Gaussian D1，区分少一步与初值的影响。CPU 使用既有冻结 xyz 命令滤波器，只吸收实际执行并确认的命令；旋转/夹爪保持最近执行值，预测50步，按当前真实输出变换的逆映射得到32维初值，后25维为零。直接替换原 AE 初始高斯张量，原 D1/D2 时间节点保持，记录此确定性初值与原噪声分布不同；不另扫噪声混合或时间起点。Full 动作不使用 Kalman。
2. **外推误差评分**：只把普通残差门控扰动改成已发生的补偿预测误差方向。首 Full 无历史使用原评分，第二 Full 用 hold 误差，之后根据实际 Full 间隔构造当前真实残差减历史预测残差。共享一次可微 D10 前向、四方向一批；每次实际 Full 评分，Fast 无额外探测，不使用未来观测。
3. **动态跳层预算**：只改变 skip 数5–8，保留普通四方向评分/D2/原外推和验证。用过去5条已执行命令、姿态变化及夹爪变化构成既有决策机风险代理。阈值由8条既有 Full 轨迹的无夹爪切换窗口 q25/q50/q85 冻结：低风险 skip8/7，一般 skip6，高风险 skip5；夹爪切换强制skip5。代理不宣称识别真实接触阶段。每次 Fast 从最近实际 Full 的同一组梯度选择合法组合，无新增反推。报告全部预算的实际占比，不能靠全部skip5冒充动态收益。

七个条件（Full基线、共同D2对照、Gaussian D1、Kalman D2、Kalman D1、误差评分、动态预算）各40例：4 suites×10 tasks×官方 init19，共280条。task0/2先跑，首批计入40例。每条件独立自由闭环、同一组初态/生成seed/20Hz执行节奏；同case条件轮换顺序，共用持续模型服务。每回合使用既有 Fresh 环境入口，在环境构造前固定seed7，沿用此前已修复的初态口径。所有有效失败保留，不重跑到成功。

关键检查只覆盖新增机制：同高斯初值的新采样入口与原生D1/D2对照；零误差方向的中性Full及零梯度；原四投影/合法mask；Kalman确认历史、当前解码坐标；动态预算因果性与非退化。已知融合反向未过旧梯度容差的事实沿用，不把严格数值等价设为本轮近似候选的前置结论。

报告：每条件成功数及相对共同对照的恢复/新增失败、实际Full比例、草稿拒绝率、AE耗时、每实际动作热态策略成本与相对Full倍速、含执行的墙钟成本、准备成本；另列Kalman CPU成本、误差方向构造成本和5–8预算分布。策略成本包括逐请求ack CPU成本（包含Kalman状态更新）、选择器收集/终端排空；图捕获单列，统一后段去掉前三个请求。每卡单环境，空闲GPU按锁和实际compute进程领取，尊重其他会话占用。
