# 周期2残差重放快速测试

四suite各10task、init19，两个候选各40条新闭环。周期为Full-D10→两次draft-D2，H50/R5。all_reuse跳过L1–17的实时hidden更新；prefix3_reuse仅L1–3实时更新，L4–17重放残差。L18仅生成K/V。所有请求仍处理当前图像、投影当前K/V并运行完整AE，不使用旧K/V或旧动作。

全复用成功20/40，低于同批V12复用参考29/40，差值-22.5个百分点、探索95%区间[-37.5,-7.5]。仅前三层更新成功28/40，比全复用多8例，差值+20个百分点、区间[+5,+35]；比V12参考少1例，差值-2.5个百分点、区间[-12.5,+7.5]。这轮支持保留少量当前hidden更新有价值；前三层方案有进一步扩样价值，但不能用40条宣称与V12等效或非劣。

当前固定输入测试中，前三层方案的draft从V12参考47.3ms降至38.0ms（约节省19.6%），计入Full刷新后从68.2ms降至62.1ms（约节省8.9%，约1.10×加速）。全复用再快约1.3ms/摊销请求，但质量下降较多。视觉、K/V、AE及周期Full都仍计算，不能按跳过的层数比例声称整体成倍加速。

V12复用为显式复用的历史参考，逐case首观测、官方init及模型路径门禁匹配才使用；不兼容则本轮重跑参考。新候选同case在同服务执行，环境每条件独立构建且构建前设seed7。

40固定真实输入、每输入每路径先预热3次再AB/BA两遍，共每卡560次测量。稳态按(含残差提取Full+2×draft)/3摊销。仅未见共卡的测速纳入上表，准备和预热成本另列。固定输入时延与不同轨迹闭环ms/动作不混为同一口径。

本轮三卡共1680个独占测量请求，另有每卡840次预热；加载及工程门禁约47–48秒/卡。详细准备/预热耗时保存在workers/gpu*/protocol.json与benchmark.json。cache_bytes记录40输入bank中所需单份FP32残差缓存的最大值：全复用约70.8MiB、前三层更新约58.3MiB、V12参考约25.0MiB；每条路径仅保留最近一次Full残差。

缓存FP32残差只保留最近一次本路径Full，Full刷新、复制/提取及修补成本均计入。历史参考的闭环墙钟来自前轮，回合耗时只作描述，不与本轮作独占因果速度比较。40条探索样本不能宣称等效、总体非劣或官方全量结果。

所有40个case的两个新条件及V12参考首观测、官方init向量一致，参考40条全部通过复用核验；没有因技术错误重跑。模型与公式门禁、跨卡一致性、周期/缓存年龄及源码hash检查通过。全部模型计算使用GPU0/2/3，未使用GPU1。
