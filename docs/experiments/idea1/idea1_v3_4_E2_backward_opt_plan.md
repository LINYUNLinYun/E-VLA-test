# E2 单次反传工程优化探测

2026-10-30。继承 single_action 的固定模型、原始观测与噪声、D2/H50/R5、BF16 权重与 FP32 RMS、第一步七维单次投影（seed 340710）、17 个门控、skip4/max2 选层。复用 task0/2 的四套件八个请求，不做新的闭环或质量重采样。原始实现保持冻结。

首先在一张空闲 4090 上测 eager 与完整前向+VJP CUDA Graph，保存一次 CPU/CUDA profiler。每请求预热，热态交替测量，边界同步，包含梯度回传 CPU、约束 mask 选择与动作输出，不含模型加载和视觉输入生成。记录准备时间、shape、显存、均值/P95，区分前向、VJP、总耗时。Graph 的静态输入更新计入热态耗时；用变化输入与噪声重放，防止测到陈旧结果。8 请求 × 每方法 10 次，首个探测先用一个请求。

数值采用同 BF16 eager 为基准：raw allclose atol=rtol=1e-5；门控梯度 atol=1e-4/rtol=1e-3；选层相同。原始与物理动作误差另存。融合/compile 若不满足，作为近似候选记录，不归为等价加速，不事后放宽阈值。固定投影、gate、噪声和输入哈希保持一致。

约 10–20 分钟有界探测：profiling 决定是否尝试局部算子融合、attention backend 或 compile。完整编译单次最多约 5 分钟，无进展即停止，保留失败原因。流水线另测共享 GPU 争用；跨观测使用旧梯度明确属于算法时序变化，不能用后台占用掩盖计算开销。结果不直接证明闭环成功率或服务端到端时延。
