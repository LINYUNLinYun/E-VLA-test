# E3两阶段补充结论

两轮按顺序完成：127个真实被拒请求，先固定两步扫描q=0.1/0.3/0.5/0.7/0.9/1，再冻结一步的q=0.8/0.9/0.95/1。偶数task的65请求选参，奇数task的62请求留出。主指标先平均两种匹配噪声，再按task/suite等权。它们是相对Full-D10的前五步动作差，不能替代闭环成功率。

## 主要结果：留出62请求

|方案|平移mm代理|旋转L2|夹爪符号差|AE ms|
|---|---|---|---|---|
|fresh Full-D1|8.308|0.1217|9.83%|7.218|
|失败draft，q=0.8，修一步|4.548|0.0333|5.58%|7.189|
|fresh Full-D2|3.800|0.0265|4.87%|14.173|
|失败draft，q=0.9，修两步|3.143|0.0238|3.25%|14.273|

**增大q改变了此前q≤0.3的结论。** q=0.9两步在留出组的平移、旋转与夹爪符号差均低于fresh D2。平移配对差−0.657mm，探索性95%区间[−0.836,−0.477]；旋转差−0.00268，夹爪差−1.625个百分点，两者逐点区间也不跨零。q=0.7平移均值略低，但调参组夹爪更差，所以按预定规则选q=0.9。q=1逐元素等于fresh D2，没有把纯噪声端点算成复用收益。

**失败draft可帮助一步推理。** 依据阶段一选择范围后，一步调参组选q=0.8。留出组相对fresh D1：平移−3.760mm，旋转−0.08846，夹爪−4.25个百分点，探索性逐点区间均不跨零。相对fresh D2，一步q=0.8仍有平移+0.748mm与旋转+0.00680的差距；夹爪差+0.708个百分点的区间跨零。它是当前已测一步网格的最佳点，位于下边界，不能声称是全局最优q。

q同时改变初始化混合权重、积分起点与Euler步长，实验支持“原先q过小限制了这套修复方法”，尚未单独隔离噪声方差、时间日程和draft信息各自的因果贡献。对Full-D10更接近也不自动等于更高任务成功率。

成本方面，两步修复和fresh D2都约14ms AE；一步修复约7.2ms AE，与fresh D1相近。当前Full前缀构建与已支付draft/verify成本仍在，不能将AE减半叫作完整fallback加速两倍。

两轮127/127数值验收通过，原Full参考、旧q0.3路径与fresh D2复现通过，q=1与同NFE fresh逐元素一致，参数选择与冻结顺序核验通过。本轮GPU0/1模型服务均已退出。
