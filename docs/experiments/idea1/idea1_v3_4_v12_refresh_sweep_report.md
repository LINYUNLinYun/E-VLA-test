# V12残差复用：刷新周期2/4/6与前三层方案对照

结论：在同40条探索闭环中，V12＋历史残差复用比前三层方案更能承受刷新间隔拉长。周期4为22/40（55%）对11/40（27.5%），周期6为11/40（27.5%）对1/40（2.5%）。同周期优势分别+27.5pp、+25pp，配对探索95%区间均为正；相对各自周期2，V12降幅分别少25pp、22.5pp。

但V12自身周期2→4→6仍从72.5%降至55%、27.5%，因此“更稳”不代表无需频繁刷新，周期4也不能声称保住原收益。这支持保留更多当前层计算的实用价值，但本轮不定位单层因果贡献。

V12跳层[2,3,5,14,16,17]，重放最近本路径Full残差；前三层方案仅L1–3当前hidden更新、L4–17重放残差。两者所有18层当前K/V、视觉、完整AE均实时。周期P=Full-D10→P次draft-D2，H50/R5。四suite各10task、init19，各40条。V12周期4/6为80条新闭环，其他160条兼容结果复用。
