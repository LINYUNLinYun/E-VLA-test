# E2：五步各0.2平均后反传

2026-10-30。复用40请求的FP32精确 Jacobian（5×7×17）及对应独立单层删除反事实，未新增GPU或闭环实验。投影种子340710–340741，共32组，与单动作实验一致。目标统一为首五步全部七维真实删除扰动的范数；表中ρ为40请求平均，随机方法再平均32种子。

五步平均动作 ā=0.2Σₜaₜ，标量 L=wᵀā，一次反传得 ∂L/∂g=0.2ΣₜJₜᵀw，覆盖全部五步。七维平均向量若要保留完整Jacobian仍有七行；任意七维线性投影只需一次VJP。

|输出组合|一次VJP ρ|四次VJP ρ|
|---|---:|---:|
|仅第一步，七维随机投影|0.30994|0.41828|
|五步各0.2平均，再七维随机投影|0.34020|0.45807|
|五步35维独立随机权重|0.32806|0.44895|

五步平均后七个维度也全用正等权：一次VJP，ρ=0.35080。五步平均的完整七行Jacobian：ρ=0.50018；五步原始完整35行：ρ=0.50282。max2约束选四层的独立单层真实扰动/全层均值分别约0.523与0.509，较低为好；不是四层同时删除后的误差。

五步平均共享同一个七维投影方向，不等于35维独立Rademacher投影：前者有跨时间交叉项，优化平均动作的敏感性；后者平方投影期望对应完整Jacobian平方范数。若不同步的导数方向相反，平均会抵消。因此此处数值接近不能证明所有轨迹、所有闭环都可替代。32种子下平均五步1次ρ的种子均值5%–95%为[0.289,0.375]，与单步和独立35维投影有重叠；未声称微小差异统计显著。

模型原前向已生成整段动作，所以五步聚合仍是一次反传，预期成本接近单步单次VJP；本轮没有测该新分支GPU时延，不能把此前Graph单步64ms直接当作该分支实测。
