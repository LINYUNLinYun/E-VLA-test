# E1：动作差下降与闭环成功率的口径核对

现有数据尚未证明“实际执行的所有关键动作都更准确，而成功率稳定下降”。L16–18的H50平均改善主要来自未执行后缀；L17–18的执行前缀平移确实改善，但夹爪、缓存年龄覆盖与自由闭环分布仍有缺口。不能用一句“动作差不等于成功率”替代机制定位。

## 真正执行的前五步

原160对同输入、同生成噪声存档，D2，各请求前五个动作，共800个相关动作位置。P90按800个位置的平移差计算，区别于逐请求五步均值的P90；夹爪符号差均相对同输入Full-D2。

|条件|平移均值 mm代理|平移P90 mm代理|夹爪符号差|至少一处夹爪符号差的请求|
|---|---|---|---|---|
|V14|6.867|11.650|27/800（3.38%）|16/160|
|旧L16–18|7.196|14.669|52/800（6.50%）|26/160|
|旧L17–18|5.817|10.926|40/800（5.00%）|21/160|

因此，原L16–18的闭环182/200→164/200，并不对应执行前缀平移差改善；其均值、尾部和夹爪符号差均恶化。后45步改善不直接贡献于此次执行，因为R=5后即重规划。

L17–18则确实降低了前五步的平移差，不能用未执行后缀解释全部现象。但夹爪符号差没有同步改善。符号差是相对Full的差异，不能直接认定这些动作错误，更不能认定它们已导致失败；尚缺失败事件处的对齐证据。

## 缓存年龄与闭环证据

误差bank只覆盖Full轨迹上的age5；两轮复用闭环包含age5与age10，并在候选自身的状态和缓存历史上运行。每task只存四个预选请求，未覆盖所有重规划，也未按接触、抓取或释放等事件采样。现有均值不能说明候选全程、两个年龄、关键阶段的动作差都改善。

保留L16–18、仅停止第二次复用的B从164/200恢复到179/200，对照周期V14为182/200。B相对旧方案恢复21例、损失6例。这支持第二次复用是重要排查对象，但不能把内部机制唯一归为age10动作误差，因为尚未在相同自由闭环输入上直接测量该误差。

L17–18两轮复用A只有34/40，同case周期V14为37/40；配对恢复2例、损失5例，探索性task聚类区间为[-20,+5]个百分点。样本未证明稳定退化。L17–18只首轮复用C为180/200，V14为182/200，差值区间[-4.5,+2.5]个百分点，也不能声称已经证明等效。

## 尚需的因果定位

在候选自身闭环输入上，以该请求的同输入、同生成噪声Full作shadow，分别统计age5和age10、前五步的平移/旋转/夹爪及尾部；对齐已配对的成功转失败案例，定位首次关键交互差异。夹爪保护或age10单独干预可进一步验证具体机制。当前数据足以纠正指标解释，尚不足以确认每个失败的原因。
