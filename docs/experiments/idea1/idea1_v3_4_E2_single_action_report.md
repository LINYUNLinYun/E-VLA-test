归一化raw动作尺度和七维权重保持原定义，平移/旋转/夹爪组合目标不同于任务成败。32组种子用于检查投影波动，未按结果选种子或最佳动作位置。不同位置的结果同时公开。
FP32输出与存档及实际梯度与完整J相应行/投影核对通过；BF16为独立近似分支，偏差记录在checks.json。forward增量仅适用于同一PyTorch路径保留计算图，原Triton Full不能直接抵扣。
