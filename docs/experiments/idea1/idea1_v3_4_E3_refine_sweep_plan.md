# E3：先验证加噪强度，再测失败draft修一步

用户要求严格按两阶段执行：先检验加噪强度，再根据第一阶段经验选择第二阶段噪声。旧E3文件不改写。

共同条件：原π0 checkpoint、BF16/Triton、完整当前Full KV、当前state、H50，拒绝动作取原E3实际V14-D2输出。仅用已冻结207请求中的127个原零接受请求，不重选样本。每个请求沿用ε0生成seed与独立ε1修复seed，保存相对Full-D10(ε0/ε1)的双参考结果；主比较为候选εs对Full-D10(εs)，跨参考结果另列。零接受包括空间/夹爪触发，不直接解释为真实任务失败。只做同输入离线重放，不执行修复动作，不声称闭环成功率或部署端到端加速。

初始化z_q=(1-q)*实际失败draft+q*ε，从q均匀Euler积分至0。q同时改变初始化混合权重、积分起点与步长，不把q扫描解释成孤立的噪声方差干预。q=1完全忽略draft，须与fresh Full同NFE逐元素一致。每个候选保存完整raw/decoded H50，分别报告前5步与全50步的平移clip后mm代理、未clip平移、旋转坐标L2、夹爪符号差、raw前6维RMS及AE/完整候选wall。视觉/VLM准备成本单列，已支付draft/verify成本不冒充节省。

在执行前按task编号奇偶固定拆分：偶数task调参（65请求），奇数task留出（62请求）；四suite分层。参数选择只读调参组；每请求先平均ε0/ε1的匹配参考指标，再按task平均、suite内task等权、四suite等权。留出结果只用于报告，不反过来调整参数。区间按suite分层task聚类bootstrap，探索性逐点区间，未作多重比较校正。

阶段一：NFE=2，q网格[0.1,0.3,0.5,0.7,0.9,1.0]，加fresh Full-D2与原失败draft锚点。全部127请求完成、核验后再做参数决定。优先选夹爪符号差不高于fresh D2的q<1，在其中选平移mm代理最小者（并列取更低q）；若没有满足者，明确记为没有该项非劣候选，诊断性选择夹爪差最小者、平移差次序破同分，不把它说成更好策略。旋转与全50步单列，不能由平移结论代替。

阶段二：先写独立冻结清单，q取阶段一选中q*及相邻q*±0.1，裁剪到[0.05,0.95]、去重；另含q=1和fresh Full-D1。NFE=1，使用同127输入、同双噪声、同Full-D10参考。用相同的调参规则选择一步主候选，然后报告其留出结果，及与fresh D1和fresh D2的配对差/区间；邻点仅作探索。若q*接近1而仍无优于fresh的点，应报告初始化信息的收益不足，不能将纯噪声端点算成复用成功。

每阶段每请求重新核对Full-D10(ε0/ε1)与已有补充存档raw/decoded相符，atol=rtol=1e-5；阶段一q0.3也核对旧修复输出。输入/原draft/参考文件hash冻结，数值核验失败停止，不放宽容差。对每种schedule先预热，再交替/反向顺序测量，预热与实际时间分开，当前Full前缀仅在同一输入的候选间复用。

GPU0/1/2/3可用，约30秒检查，连续约60秒无其他compute且显存≤1500MiB才启动。最多两个持续模型服务，按task分配；已有足够资源不再扫描其他卡。启动OOM保留并有界恢复，每GPU最多2次；有效数值不合格不重跑挑结果。两个阶段共用服务，第一阶段完成并冻结第二阶段配置之前不得生成第二阶段候选。

交付：冻结manifest和阶段二清单、参数决定、127逐请求双噪声raw/decoded/指标、q曲线、独立调参/留出汇总、一步与fresh D1/D2配对比较、数值验收与中文结论。父系统37/40不作为本轮修复策略成绩。
