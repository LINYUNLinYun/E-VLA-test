# v4.3：Kalman从位置三维扩展至位移、旋转六维

用户要求检验此前旋转命令保持是否导致Kalman流匹配起点效果不佳。保留v4.1完整策略：π0 BF16、动态V12 skip6非相邻、原四投影与层RMS评分、周期3、实际Full残差外推、原验证及夹爪保护、H50/R5、20Hz、四LIBERO套件task0–9/init19。选择器图保留，encoder、AE、验证不上图。这里仍有正常Full动作与拒绝接管，不与v4.2仅刷新残差的系统混合。

六维指控制器已执行、已clip至[-1,1]的三维位移和三维旋转增量命令；不是直接对绝对Euler角或四元数做线性外推。位置CommandKalman与其冻结参数、经验Q形状逐位保持。旋转新增独立三维CommandKalman，采用相同q_u/q_w/g/beta与单位Q/R形状，不把平移校准的轴间协方差移植到旋转；本轮不额外调旋转噪声参数。两滤波器只在ack时吸收实际执行命令，预测不改变后验。夹爪保持最后执行值；25个padding先验为零。坐标编码仍逆变换当前观测的真实affine decoder。

沿用修正后的时间编码。起点公式仍为x_tau=(1-tau)*KF_raw+rho*tau*epsilon，从tau积分到0。扫描tau=.05/.10/.20/.35/.50/.75、rho=0/.5/1、D1/D2，共36组，全部只做同观测离线筛选，不宣称36组全部闭环。

复用v4.1相同8例、48个真实Fast输入和其真实mask/Full历史，保证Kalman只读取各观测之前的已执行动作。在同一前缀和噪声上比较原始三维/六维Kalman、修正Gaussian D1/D2、旧三维冠军对应参数的三维与六维候选。报告位置和旋转误差、七维命令MSE、夹爪差异、验证接受率与AE成本。参考是Full-D10同观测输出，并非真值。

新闭环先在task0/2的8例调参：六维每D按离线MSE取前两名，并强制加入与旧三维冠军同参数的两个锚点（D1 tau=.75 rho=1、D2 tau=.05 rho=1），最多6个六维候选；另有新跑的修正Gaussian D1。按成功数、热态策略成本、ID为每D选一名。剩余32例确认始终跑两个固定参数锚点、任何不同的冻结冠军，以及Gaussian D1。最多216条新闭环；同一条件的调参8例计入最终40例，不重复。旧三维两冠军及修正Gaussian D2各40条符合协议的v4.1结果只读复用，源文件和数据身份固定。

核心问题通过相同tau/rho/NFE下的三维→六维配对回答；重新调参后的冠军另列，避免将参数变化全归因于姿态预测。所有40例成功数保留描述；首Full输入/原始输出未过原atol=rtol=1e-5时保留有效结果，从相关严格配对剔除并公开实际n，不放宽容差或重跑到匹配。新Gaussian D1用于分离一步AE与起点的影响。

CPU检查位置输出逐位不变、旋转通道正确、夹爪保持、预测不修改后验且无未来输入。GPU仅检查既有采样端点、节点和六维编解码/因果计数/真实策略smoke。新旧均为实际20Hz动作节奏；热态去前三请求及显式选层捕获，包含额外旋转预测、坐标编码、ack、验证/Full回退与终端排空。另报AE耗时、Full比例、拒绝率、准备成本、闭环墙钟与吞吐。
