# v3.4 E3 补充：初始化与噪声身份控制

当前主实验冻结方案保持不变。本补充针对已观察到的一个解释限制：主E3的fresh Full-D2和Full-D10参考共享生成噪声ε0，重加噪修复使用独立ε1。二者对参考的接近程度同时受噪声身份影响，不能全部归因于初始化优劣。

在执行前冻结全部207个已固定选择的E3请求（零接受127、非零接受80），不再挑误差/成败或扩大样本。保存每个请求输入、原shadow、实际前一raw动作与实际执行长度的SHA。使用当前Full KV、当前state，比较：Full-D2/D10从ε0或ε1起采样；原拒绝/接受draft在q0.3以ε0或ε1重加噪修复2步；上一轮剩余动作在q0.3以ε0或ε1修复2步（缺历史则不可用）。q保持0.3，不调参。ε1沿主E3的独立refine seed。

分别相对Full-D10(ε0)和Full-D10(ε1)计算前5/全50 decoded平移、旋转、夹爪与raw误差，保留双参考，避免单一噪声参考的偏好。记录AE成本与当前Full准备成本。此补充不执行动作、不重新做任务成功率，不使用旧KV验证接受率挑选候选。

只在GPU2原worker已实际退出且GPU空闲后加载补充服务。复用原4套件真实输入门，并在每条补充样本上核对重新计算的Full-D10(ε0)与原存档raw/decoded输出，预定atol=rtol=1e-5；失败则停止，不放宽。原draft和实际上一轮剩余动作直接来自父系统存档，不用新服务生成的动作冒充原被拒动作。

交付固定manifest、207请求逐候选双参考raw/decoded动作及指标、分组汇总、配对噪声结论与验收收据；合入E3报告，同时保留原207请求结果。它仍只回答动作空间机制，不证明修复策略闭环质量。
