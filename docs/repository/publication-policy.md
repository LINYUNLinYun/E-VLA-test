# 发布范围

- 保留各版本实验设计、最终结果分析及配套轻量图表，包括 v1/v2。
- v1/v2 的中间结果、进程状态、机器审计、逐案例原始记录不上传。轻量运行汇总以 v3.0 及以后为主。
- 保留开发需要的模型和 benchmark 源码、实验实现、测试与配置。旧通用代码仍被后续版本调用时继续保留。
- 重复的运行源码快照、历史源码归档和视频索引不上传；少量独立运行辅助脚本按用途保留。
- 视频、权重、数据集、张量、完整逐请求流、环境和缓存不上传。仿真资产按记录的上游 commit 恢复，模型和数据在实验机器上下载。
- 普通文件不超过 10 MiB，图和 PDF 不超过 1 MiB。

具体清单见 `snapshot_files.tsv`，计数和排除规则见 `snapshot_summary.json`。通用导出工具不替代版本及产物筛选；再次导出后应检查实际 Git 包体积。
