# 发布内容与来源

保留开发源码、各版本设计与最终结果分析（含 v1/v2）及配套轻量图表。v1/v2 的中间结果和机器审计不上传；轻量运行汇总以 v3.0 及以后为主。重复运行源码副本与大产物不上传。

当前来源文件 **11,486 个，未压缩 332.0 MiB**；另有少量协作文档和发布工具。主要目录分布见[摘要](snapshot_summary.json)。

- [源码文件与 SHA256](snapshot_files.tsv)：仅用于导出追溯；后续正常开发不要求沿用旧 hash。
- [20 个上游仓库及版本](upstreams.json)：记录来源 commit、本地 tracked 改动路径和缺失仿真资产。
- [排除范围](excluded_files.json)：按类别说明，不复制原工作区的庞大审计目录。
- [发布规则](publication-policy.md)与[新机器复现说明](../setup/remote-reproduction.md)。

原工作区在导出时仍有实验运行，各文件有独立 hash，但不是所有任务同一时刻的事务快照。报告中的历史绝对路径、进程、lease 和 running 状态不是当前远程任务状态。原始输入和完整原始证据可能需要在实验机器下载或重新生成。

本次检查包括来源 hash、大小与疑似密钥扫描、新文档链接、发布工具语法，以及按固定 commit 恢复缺失资产的离线检查。没有重新运行 GPU 或闭环实验。
