# 固定前后trial切分的历史稳定性复核

这是回顾性探索：在已经看过总体和逐task汇总后，固定使用trial0–4学习、trial5–9评估，没有搜索其他切分。原800条历史episode只提供名义case配对，没有物理初态hash；不能把这项检查称为新的独立复现。

方法事先写入本目录protocol.json：分别按既有4类metadata标签或40个task，从训练半部选择成功数较多的L2/L8；平局固定选L2。固定路径基线也只用训练半部选择。冻结输入文件SHA，脚本不允许更改protocol后重新匹配结果。

训练半部200对：L2成功177，L8成功174，因此固定基线选择L2。评估半部200对：L2成功179，L8成功180。按metadata类别选择和按task选择均为181/200，相对训练选择的固定L2多2条（+1pp），相对评估半部更好的固定L8多1条（+0.5pp）。这只是旧数据的离线检查，没有验证在线选择算法或成本收益。

两种路由相对训练选择基线的40-task条件bootstrap区间均为[0,2.5]pp；区间包含0，且仅条件于已经拟合的选择规则，没有计入训练选择的不确定性。40个task中，35个至少一半为平局，4个两半非零差值方向相同，1个相反。这些少量差异仍不足以认定稳定类别偏好。

本复核只用于判断候选是否值得新实验，不改变当前VLM local-search manifest/队列/选择标准，也不证明自适应路径已有收益。源码为analyze.py；数值与选择列表为analysis.json。
