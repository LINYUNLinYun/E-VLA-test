# 固定 VLM 组件路径：注意力与 FFN

本轮比较两条固定子路径：在相同的第4、7、10、13、15、17层，一条跳过注意力隐藏更新，另一条跳过FFN。跳过注意力时仍计算当前观测的K/V；第18层保持原始QKV-only。两路相机完整新编码，动作专家保留18层。每个Full D10之后执行两次Fast D2，跳过模块用最近两次Full的FP32残差作外推补偿。没有新增训练或在线选择器。

22项CPU检查通过；365份Python源及[协议](protocol.json)已在GPU运行前冻结。[校准已通过](calibration_acceptance.json)：四个服务均完成真实bank数值参考检查，8条已知Full/DenseD2轨迹逐位一致，1152次成本调用验收通过。Full/path为注意力路径1.544、FFN路径1.601，配对成本差3.7%，满足预定门槛。

[160条新闭环探索](prelaunch_discovery.json)已在原有两张GPU启动，目前不读取未完成矩阵的成功率。后续800条条件复验的统计和审计流程已通过19项额外CPU检查（含合成800案例正例及反例），[仍锁定](confirmation_preparation.json)，没有创建真实确认manifest或读取确认结果。这些未来专用源码在本轮365份source冻结后添加，不被当前GPU运行导入。
